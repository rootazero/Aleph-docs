`domain` 模块使用领域驱动设计 (DDD) 原则实现 Aleph 的领域模型。它定义系统的核心词汇 —— 什么是会话、任务的含义、意图的结构 —— 独立于任何基础设施或框架问题。

## 设计理念

领域层遵循三个 DDD 原则：

1. **纯领域逻辑** — 无数据库查询、无 HTTP 调用、无文件 I/O
2. **类型安全边界** — 无效状态通过类型系统无法表示
3. **显式不变量** — 领域规则在构造时强制执行，而非稍后检查

此模块不依赖于 `tokio`、`axum` 或任何异步运行时。它可以使用普通的 `#[test]` 函数进行测试，无需运行时。

## 核心 Traits

领域层以三个**最薄**的 marker trait（`src/domain/mod.rs`）建立通用语言 —— 不规定字段，只规定身份和等价的语义。

### Entity

具有唯一、不可变标识的对象，该标识在状态更改期间保持不变。

```rust
pub trait Entity {
    type Id: Eq + Clone + std::fmt::Display;
    fn id(&self) -> &Self::Id;
}
```

实体按身份而非属性进行比较。两个具有相同 `session_id` 的 Session 对象是相同的实体，即使它们的其他字段不同。

**示例：** `Session`, `Task`, `Agent`

### AggregateRoot

聚合的入口点 —— 一个一致性边界，在多个实体之间强制执行领域不变量。

```rust
pub trait AggregateRoot: Entity {}
```

AggregateRoot 是外部代码可以直接引用的唯一对象。聚合中的所有其他对象都通过它访问。**注意：实际 trait 不带 `version()` 方法** —— 版本号由各聚合实现按需提供，不是 trait 的一部分。

**示例：** 任务与依赖组成的图是聚合的概念示例；当前源码的持久记忆记录为 `MemoryFact`（`src/memory/context/fact.rs`）。

### ValueObject

完全由其属性定义的不可变对象。具有相同属性的两个 ValueObject 相等且可互换。

```rust
pub trait ValueObject: Eq + Clone {}
```

ValueObject 没有身份 —— 它们是纯数据。更改任何属性都会创建一个新的 ValueObject。**注意：实际 trait 不带 `validate()` 方法** —— 校验由具体类型的构造器（`parse, don't validate`）或领域用例承担，不在 trait 契约里。

**示例：** `TaskStatus`, `NoteType`, `GuestScope`, `FileContent`

## 领域类型

### Credentials

代表认证凭据的**枚举**，不是结构体（`src/a2a/domain/security.rs`）。

```rust
pub enum Credentials {
    BearerToken(String),
    ApiKey(String),
    OAuth2Token(String),
    None,
}
```

`Debug` 实现把每种变体都打成 `[REDACTED]`，不让 secret 落进日志。`Credentials` 由 `A2A` 协议适配器在远端握手时使用，不属于本仓库的 `domain` 模块。

### TrustLevel

`skill` 模块用来决策技能安装的信任级别（`src/skill/guard.rs`）。

```rust
pub enum TrustLevel {
    Builtin,    // Aleph 自带，始终信任
    Trusted,    // 已知/已策展的发布者
    Community,  // 任意第三方（clawhub 默认）
}
```

由 `install_allowed(ThreatLevel, TrustLevel)` 给出决策表 —— 不是从网络源自动推断。

### FileContent

`A2A` 规范下文件内容的载荷形式（`src/a2a/domain/message.rs`）。

```rust
pub struct FileContent {
    pub name: Option<String>,
    pub mime_type: Option<String>,
    pub bytes: Option<String>,  // Base64 编码
    pub uri: Option<String>,
}
```

`validate()`（`pub const`，返回 `Result<(), &'static str>`）只检查 `bytes` 与 `uri` **恰好有一个**被设置 —— 既没有也不行，两个都有也不行。它**不**检查 MIME 解析、文件名转义或非空载荷：那些在序列化层处理。

## 限界上下文

Aleph 的领域被组织成限界上下文，每个上下文都有自己的通用语言：

| 上下文 | 关键类型 | 位置 |
|---|---|---|
| **Memory** | `MemoryFact`, `FactSource`, `NoteRelationArg` | `src/memory/` |
| **Identity** | `IdentityContext`, `GuestScope`, `Role` | `shared/protocol/src/auth.rs`、`src/gateway/session_manager/` |
| **Skill** | `TrustLevel`, `ThreatLevel` | `src/skill/guard.rs` |
| **A2A** | `Credentials`, `FileContent`, `SecurityScheme` | `src/a2a/domain/` |
| **Loop-Graph Governance** | `NodeKind`, `EdgeKind` | `src/loop_graph/types.rs` |
| **Goal** | `Goal`, `GoalStatus`, `PursuitMode`, `GateOutcome` | `src/goal/types.rs` |
| **Artifact** | `ArtifactRecord` | `src/artifacts/store.rs` |
| **Team** | `TaskStatus`, `ArtifactType` | `src/teams/artifacts.rs` |

跨上下文引用走显式映射层 —— `IdentityContext` 在 `aleph_protocol`（跨进程共享），而 `src/memory/` 持有自己的 `MemoryFact` 与 `FactSource`，两者不直接共用类型。

## 实践中的设计模式

### Newtype 类型安全

```rust
pub struct SessionId(String);
pub struct TaskId(String);

// 不能意外地在期望 SessionId 的地方传递 TaskId
fn load_session(id: SessionId) -> Option<Session> { ... }
```

### 枚举状态机

`TaskStatus`（`src/teams/artifacts.rs`）的形态：

```rust
pub enum TaskStatus {
    Pending,
    InProgress,
    Completed,
    Blocked,
    Failed,
}
```

非法状态无法表示 —— 任务不能同时处于 `Pending` 和 `Completed` 状态。

### 解析，而非验证

```rust
impl Email {
    pub fn parse(input: &str) -> Result<Self, ValidationError> {
        // 在边界拒绝无效输入
        // 返回保证有效的类型化 Email
    }
}
```

## 26.7.x 补充

### POE 上下文已退役

POE（Principle-Operation-Evaluation）运行时架构在 26.5+ 退役。其「智慧」已迁移到 system prompt 模板（R9）；成功定义、验证、评估现在由 LLM 一次调用自然完成。Harness 不做完成度判断（**R10「5 个不」之 3**），不参与评估。

历史 POE 类型已从当前源码移除；需要考古时应查阅对应版本的 Git 历史，而不是引用当前模块路径。

### 新增限界上下文

- **Loop-Graph Governance 上下文**（`src/loop_graph/`）—— 团队节点 / 审计环 / 客观 ACL / 胜利声明 watcher / 内置 `loop-auditor`
- **Goal 上下文**（`src/goal/`）—— 持久目标；由 `GoalStore` 管理；带 maker/checker 拆分的 `GateOutcome`
