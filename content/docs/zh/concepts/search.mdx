`search` 模块为 Aleph 提供实时 Web 搜索，使代理能够访问其训练数据截止日期之外的当前信息。它通过统一的 trait 接口支持多个搜索后端。

## 设计理念

搜索系统遵循三个原则：

1. **提供商抽象** — 所有搜索后端实现相同的 `SearchProvider` trait
2. **隐私优先** — 支持自托管的 SearXNG 以及商业提供商
3. **故障转移路由** — 注册表尝试提供商直到一个成功

## 核心类型

### SearchResult

所有提供商的统一结果结构：

```rust
pub struct SearchResult {
    pub title: String,
    pub url: String,
    pub snippet: String,
    pub relevance_score: Option<f32>,   // 0.0–1.0，Tavily 原生；其他计算
    pub full_content: Option<String>,   // 仅 Tavily 深搜索
    pub provider: Option<String>,
}
```

### SearchOptions

搜索行为的配置：

```rust
pub struct SearchOptions {
    pub language: Option<String>,        // ISO 639-1
    pub region: Option<String>,          // ISO 3166-1 alpha-2
    pub date_range: Option<String>,      // "day" / "week" / "month" / "year"
    pub safe_search: bool,               // 默认 true
    pub max_results: usize,              // 默认 5，上限 50
    pub timeout_seconds: u64,            // 默认 10，验证后 ≥ 1
    pub include_full_content: bool,      // 仅 Tavily
}
```

`SearchOptions` 同时承载每个提供商的规范化映射（`language` / `region` / `date_range` / `safe_search` → 提供商原生参数），新增 provider 仅需扩展该映射表。

### SearchProvider Trait

```rust
#[async_trait]
pub trait SearchProvider: Send + Sync {
    async fn search(
        &self,
        query: &str,
        options: &SearchOptions,
    ) -> Result<Vec<SearchResult>>;

    fn name(&self) -> &str;
    fn is_available(&self) -> bool;

    fn capabilities(&self, options: &SearchOptions) -> SearchCapabilities;
}
```

trait 现在住在 `crates/aleph-slot-api/src/search.rs`（P0 模块化后 `src/search/provider.rs` 只是同义 re-export）。没有配额 API：配额耗尽表现为 `AlephError::RateLimitError`，由错误分类落成 `SearchErrorKind::Quota`。`SearchCapabilities` 有 `domain_filter` / `recency` / `full_content` 三个位，默认全 false（能力声明按请求推导，不是恒真）。

## SearchRegistry

通过具名 default + fallback 链管理多个提供商：

```rust
pub struct SearchRegistry {
    providers: HashMap<String, Arc<dyn SearchProvider>>,
    default_provider: String,
    fallback_providers: Vec<String>,
    config_defaults: Option<SearchOptions>,
    web_fetch_fallback: Option<Arc<WebFetchSerpFallback>>,
    health: ProviderHealth,
}

impl SearchRegistry {
    pub async fn search(
        &self,
        query: &str,
        options: &SearchOptions,
    ) -> Result<Vec<SearchResult>> {
        // 1. 尝试 default_provider
        // 2. 顺序尝试 fallback_providers
        // 3. 全部失败后尝试 web_fetch_fallback（默认武装）
        // 4. 仍然失败：聚合错误信息
    }
}
```

**错误分类：** `SearchErrorKind::of` 把 `AlephError` 折叠成八种 kind —— `transient` / `quota` / `auth` / `config` / `invalid-response` / `request-rejected` / `cancelled` / `other`，标签由 `SearchErrorKind::as_str` 给出，便于按 kind grep 日志。kind 是从错误变体**推导**出来的，不是随错误携带的字段。

**聚合错误：** 所有提供商都失败时（包括最后的 WebFetch 回退），最终错误串以 `All search providers failed:` 为前缀并附上每一步的 kind + 错误信息——审计员能看出最后兜底是否真的被尝试。

**隐私说明：** 用户查询文本不在注册表失败消息中；但每条提供商失败仍以结构化 `provider=... kind=...` 形式记录，供运维按 kind 检索。

## 支持的提供商

| 提供商 | 自托管 | API 密钥 | 说明 |
|---|---|---|---|
| **Tavily** | — | ✅ | AI 优化搜索，推荐默认；提供原生 relevance + 深搜索 full_content |
| **SearXNG** | ✅ | — | 隐私优先，完全自托管 |
| **Brave** | — | ✅ | 隐私 + 质量平衡 |
| **Google CSE** | — | ✅ | 全面覆盖 |
| **Bing** | — | ✅ | 成本效益高 |
| **Exa.ai** | — | ✅ | 语义/神经搜索 |
| **Jina** | — | ✅ | 神经搜索 |
| **DuckDuckGo** | ✅ | — | HTML 抓取，无密钥 |
| **Firecrawl** | — | ✅ | 搜索 + 全量抓取；与 fetch 共享配置 |

provider 的身份是 `provider_type` 字符串（如 `tavily` / `searxng`），代码里没有 provider 类型枚举；支持列表的单源是 `ProviderFactoryRegistry::known_provider_types()`。`from_config` 用 `ProviderFactoryRegistry` 实例化已配置的 backend，未知 / 缺凭据会被跳过并 WARN。

## 提供商测试

测试配置而不保存凭据：`search.test` RPC 从 vault 解析 api_key，用 `ProviderFactoryRegistry` 构造 provider，跑一次只取一条结果的 live search。

```rust
pub struct SearchTestResult {
    pub success: bool,
    pub message: String,
}
```

成功时把该 backend 的 `verified` 置为 true 并落盘；失败只回一句 message。**结果不缓存** —— 每次点按都实打实探一次。

## 使用示例

```rust
use alephcore::search::{SearchProvider, SearchOptions};
use alephcore::search::providers::TavilyProvider;

let provider = TavilyProvider::new("tvly-xxx".to_string())?;
let options = SearchOptions::default();

let results = provider.search("Rust programming language", &options).await?;

for result in results {
    println!("Title: {}", result.title);
    println!("URL: {}", result.url);
    println!("Snippet: {}\n", result.snippet);
}
```

## 安全属性

- **错误聚合含 kind 标签** — `SearchErrorKind::of` 把 `AlephError` 折叠成稳定的 kind 字符串，便于按 kind grep 日志（不含用户查询文本）
- **安全截断** — `latency_ms = elapsed.min(u32::MAX as u128) as u32` 防止延迟饱和到 `u32`
- **无锁中毒** — 所有 `lock()` 调用都走 `unwrap_or_else(|e| e.into_inner())`
- **max_results 上限** — `validated_max_results()` 把 `max_results` 夹到 `[1, MAX_SEARCH_RESULTS]`（100）
- **timeout 验证** — `validated_timeout()` 把 `timeout_seconds` 钳到 ≥ 1
- **测试不缓存** — `search.test` 每次都实探一次，不缓存结果
