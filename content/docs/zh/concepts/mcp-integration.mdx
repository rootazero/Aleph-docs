Aleph 的 MCP 主机管理外部服务器连接；原生文件、Shell 和其他内置能力不属于 `McpClient`。服务器通过 stdio、HTTP 或 SSE 传输连接，初始化握手协商协议版本并保存服务器能力。

## 连接与传输

`ExternalServerConfig` 保存服务器名称、命令、参数、环境、工作目录、运行时要求和超时。连接层支持：

- `StdioTransport`：本地子进程；
- `HttpTransport`：远程 HTTP POST；
- `SseTransport`：远程 HTTP + SSE，可接收服务器通知。

连接初始化后按分页读取 `tools/list`，将工具规范化并以 `<server>:<tool>` 命名空间注册。工具描述被视为不可信输入；Schema 会规范化，MCP annotations 只保守地影响调度与确认，不替代安全策略。

## 能力门控

MCP 初始化响应中的 `ServerCapabilities` 区分 `tools`、`resources` 和 `prompts`。连接层只有在服务器声明相应能力时才调用 `resources/list`、`resources/templates/list` 或 `prompts/list`；列表结果会缓存并处理分页。

MCP 工具桥会根据当前健康服务器的实际能力动态注册工具：

| 能力 | 工具 |
| --- | --- |
| 至少一个资源或资源模板 | `mcp_list_resources`、`mcp_list_resource_templates`、`mcp_read_resource` |
| 至少一个提示 | `mcp_list_prompts`、`mcp_get_prompt` |
| 至少一个远程 HTTP/SSE 服务器 | `mcp_login` |

资源读取与资源发现共用一个门控，模板专用服务器也会获得读取和发现工具；提示读取与提示发现同样成对出现。没有对应能力时，工具从注册表移除，模型不会看到一个必然失败的工具。

## 按需发现

资源和提示不建立预先提示索引。当前路径是 `mcp_list_resources`、`mcp_list_resource_templates` 和 `mcp_list_prompts`，模型先发现，再把返回的精确不透明 ID 交给读取工具。针对文件的 `cat` 读取会被 read-steer 引导到 MCP、技能或插件读取路径。

MCP 工具还可以通过 `[tools] defer_mcp_tools` 放入渐进披露的延迟层，再由 `tool_search` 检索；这与资源/提示的 capability gate 是两件事。

## 资源、模板与提示的命名

服务器返回的资源和提示会带服务器命名空间。发现工具构造的 ID 必须原样复制，不应手工缩短或拼接：缓存资源本身已经是 `<server>:<uri>`，发现输出再包一层服务器前缀，以保证读取工具先剥离发现层、再由客户端剥离连接层，最终把原始 URI 交给服务器。资源模板保留未加前缀的 RFC 6570 模式，填充后按返回的服务器限定形式读取。

服务器 ID 本身可以包含冒号。`McpClient` 和 `mcp_read_resource`/`mcp_get_prompt` 共用最长前缀规则：从限定字符串最右侧的冒号开始尝试候选，选择已注册的最长 `<server>:` 前缀，再只剥离一层。这样 `gh:sub` 与 `gh` 同时存在时，`gh:sub:file:///x` 会路由到 `gh:sub`，不会被错误地送到 `gh`。

## 配置与安全

MCP 管理器负责服务器启停、健康状态、能力变更事件、聚合和配置重载。远程连接使用配置的 HTTP/SSE 传输和 OAuth 登录工具；本地服务器启动前会检查声明的 Node、Python、Bun 等运行时。服务器工具的 allow/deny 过滤发生在 `tools/list` 进入注册表时，拒绝的工具不会注册或展示；执行层仍保留 Aleph 自身的权限、确认和沙箱边界。

客户端会无条件广播已接线的 sampling 能力，并按服务器返回结果协商协议版本。资源/提示列表变化通过 MCP manager 事件传播，工具桥据此同步注册表。

## 代码位置

- `src/mcp/client.rs` — 外部连接注册、工具/资源/提示查找与最长前缀匹配
- `src/mcp/external/connection.rs` — 初始化、能力检查、分页和缓存
- `src/mcp/protocol.rs` — MCP 初始化与能力类型
- `src/mcp/tool_bridge.rs` — capability-gated 工具注册
- `src/builtin_tools/mcp_resource.rs` — 资源发现、模板发现与读取
- `src/builtin_tools/mcp_prompt.rs` — 提示发现与读取
- `src/mcp/resources.rs`、`src/mcp/prompts.rs` — 管理器接口
- `src/tools/adapters/mcp_adapter.rs` — MCP 工具执行适配
