> **状态（2026-07）：ClawHub 不再作为一等源可达。** 专属的 `src/clawhub/` 模块已退役；指向它的 Settings 标签页被移除并并入 Settings → Advanced。ClawHub 内容的浏览、搜索、安装现统一通过[扩展商店](./extensions-store)进行，后者门面化 **aleph-hub** 目录（`https://hub.heyaleph.com/catalog.json`）以及 Claude / Aleph 插件市场、Official MCP Registry、Docker MCP Catalog。当前源码中 `clawhub` 仅以两种方式出现：作为 `HubCatalog` 条目上的 `via` 来源标签（当某 artifact 可溯源到 OpenClaw 上游时），以及作为 `markdown_skill` 加载器仍识别的 OpenClaw `ClawHub` SKILL.md 元数据命名空间（兼容旧式安装）。本页仅作历史参考保留。

## 设计理念（历史）

ClawHub 集成在彼时遵循两个原则：

1. **只读访问** —— 客户端从注册表拉取技能；既不上传也不修改注册表内容。公共 API 访问不需要认证。
2. **干净的类型分离** —— 原始 API 类型通过 `From` 实现转换为内部统一类型，使 HTTP 层与领域逻辑解耦。

## 历史 HTTP 客户端

已退役的 `clawhub` 模块曾暴露一个 HTTP 客户端与类型定义，用于与 `https://clawhub.ai` 上的 ClawHub 技能注册表交互。该模块已从 `src/` 移除；以下片段反映历史 API，保留供归档参考。

### ClawHubClient（历史）

```rust
pub struct ClawHubClient {
    base_url: String,
    client: reqwest::Client,
}

impl ClawHubClient {
    pub fn new() -> Self { /* ... */ }

    pub async fn browse(
        &self,
        category: Option<String>,
    ) -> Result<Vec<SkillSummary>, ClawHubError> { /* ... */ }

    pub async fn search(
        &self,
        query: &str,
    ) -> Result<Vec<SkillSummary>, ClawHubError> { /* ... */ }

    pub async fn download(
        &self,
        slug: &str,
    ) -> Result<Vec<u8>, ClawHubError> { /* ... */ }
}
```

**历史行为：**

- `browse` 在浏览端点返回空时回退到 `search`。
- `download` 在临时文件名中使用前清理 slug（把 `/` 替换为 `-`）。
- 所有方法均使用 `?` 或 `map_err` 进行错误传播。

## 历史 API 操作

### 浏览

按类别列出技能。若类别端点返回空则回退到搜索。

### 搜索

跨注册表的全文搜索。

将技能包作为 ZIP 归档获取。

## 历史工具函数

### URL 编码

```rust
pub fn encode_slug_path(slug: &str) -> String
```

用于 URL 的每段百分比编码。

### 版本比较

```rust
pub fn is_newer_version(current: &str, latest: &str) -> bool
```

比较两个语义化版本字符串。对非 semver 输入回退到字符串比较。

### 时间戳转换

```rust
pub fn unix_ms_to_rfc3339(ts: i64) -> String
```

将 Unix 毫秒转换为 RFC 3339 格式。对无效时间戳返回空字符串。

## 历史错误处理

客户端使用 `reqwest` 进行 HTTP，所有操作返回 `Result<T, ClawHubError>`。错误覆盖：

- 网络故障
- HTTP 非 2xx 状态码
- 响应解析失败
- 下载期间的文件系统错误

## ClawHub 在当前代码中的出现位置

| 位置 | 作用 |
|---|---|
| `src/hub/catalog_client.rs` | `HubCatalog` 条目上的 `"via": "clawhub"` 来源标签 —— 仅当某 artifact 溯源到 OpenClaw 上游；标签是纯信息性的，从不触发网络拉取。 |
| `src/hub/types.rs` | `ExtensionEntry` 上的 `via` 字段；同样仅作信息。 |
| `src/tools/markdown_skill/spec.rs` | `OpenClaw` 元数据命名空间（`ClawHub` SKILL.md 兼容） —— 加载器仍解析旧式 `ClawHub` 风格 SKILL.md frontmatter，使既有技能继续可装。 |
| `src/skill/guard.rs` | 扫描技能目录时跳过 `.clawhub.json` 附属文件。 |

ClawHub HTTP 客户端本身已不在 `src/` 中；没有 `clawhub.*` 网关 RPC，也没有与 `clawhub.ai` 通信的安装器。
