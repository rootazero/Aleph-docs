Aleph 默认读取 `~/.aleph/config.toml`；`ALEPH_HOME` 可覆盖配置和数据根目录。值支持 `${VAR}` 与 `${VAR:-default}` 插值。

## Canonical schema

```toml
[general]
default_provider = "claude"
fallback_providers = ["openai"]

[providers.claude]
provider_type = "claude"
enabled = true
api_key = "${ANTHROPIC_API_KEY}"
models = ["<model ID>"]

[policies]
mode = "work"       # chat / work / code
exec_tier = "auto"  # ask / auto / full

[gateway]
host = "127.0.0.1"
port = 18790
allow_insecure_remote = false
```

`[providers.<name>]` 是提供商表；`general.default_provider` 与 `general.fallback_providers` 引用表名。模型 ID 应以当前模型目录和 Panel 配置为准。

`[policies]` 保存全局 `mode` 与 `exec_tier`。`[sandbox.command_policy]` 是不能被 `exec_tier` 降低的独立安全硬底。不要把会话模式、执行等级或不存在的 `agents.defaults.thinking` 放进 `[agents.defaults]`；该表只放 Agent 定义支持的默认值，例如模型、工作区和技能。

## Gateway host、TLS 与可信代理

```toml
[gateway]
host = "0.0.0.0"
port = 18790
allow_insecure_remote = false

[gateway.tls]
enabled = true
# cert_path = "/path/to/cert.pem"
# key_path = "/path/to/key.pem"
# san = ["aleph.example.com"]

[gateway.trusted_proxy]
enabled = true
trusted_ips = ["127.0.0.1", "::1"]
```

Gateway WebSocket 路径是 `/ws`。启用 TLS 且未提供证书和密钥时，核心生成并持久化自签名证书，远程客户端使用 `wss://`。只有直接对端属于 `trusted_ips` 时，才信任 `X-Forwarded-For` 与 `X-Forwarded-Proto`。非环回远程绑定默认拒绝明文连接。

## 重载影响

配置重载影响由 `src/config/reload_impact.rs` 分类。provider 配置、模型目录与故障转移链、通道启停以及 `[execution]` 运行上限可热重载；监听地址、端口和 TLS 证书属于传输设置，通常需要重启。重载失败时不要假定部分字段已生效；以运行中的配置和 `aleph-server doctor`、`aleph-server status` 为准。

## 相关位置

- `~/.aleph/config.toml`：主配置
- `~/.aleph/defaults.toml`：默认值覆盖
- Gateway：`config.schema`、`config.get`、`config.patch`、`config.reload`
