`src/browser/` 为浏览器工具提供统一的 `BrowserBackend`，当前由 `BrowserManager` 按 profile 选择两个后端：托管浏览器使用 `PlaywrightCliBackend`，已有 Chrome 会话使用 `ChromeMcpBackend`。浏览器自动化通过内置的 `browser_*` 工具暴露；它不是 Panel Canvas 或 Browser inspector 的 API。

## 统一后端接口

`BrowserBackend` 提供打开、关闭、列出和导航标签页，按快照引用点击、输入、填充、悬停、滚动、截图、快照、执行 JavaScript 和选择下拉项，并为历史导航、等待文本、控制台、网络日志、PDF、对话框、拖放、上传、调整窗口、模拟环境、Cookie 和存储状态提供可选能力。

快照是面向模型的结构化页面视图，使用 `ActionTarget::Ref` 引用可交互元素。两个后端不承诺完全相同的动作集合；trait 默认对未实现动作返回 `Unsupported`，调用方必须遵循实际后端能力。

## Playwright CLI 后端

`PlaywrightCliBackend` 通过 `playwright-cli` 驱动托管浏览器：

- 可启动受管的 Chromium/Chrome 等浏览器会话，并支持 headless/headed 配置；
- 导航、截图、DOM/ARIA 快照和文本交互走 CLI 会话；
- 点击等操作可使用快照引用，部分输入操作也支持当前焦点；
- Cookie 管理以及 cookies + localStorage 的 storage state 保存/恢复由该后端提供；
- 通过 profile/session key 隔离浏览器状态。

## Chrome DevTools MCP 后端

`ChromeMcpBackend` 通过 Chrome DevTools MCP 操作已有 Chrome 会话：

- 页面 ID 是数字型 tab 标识，操作前选择目标页面；
- 每个 profile 有串行锁，覆盖页面选择和动作调用，避免并发操作串页；
- 元素操作使用 `browser_snapshot` 返回的 ref，不支持坐标点击；
- 支持已有页面、标签页切换、控制台、网络、截图和 DevTools 提供的交互；
- 导航前由浏览器 SSRF guard 检查 URL，并为 Chrome 连接准备 host resolver pin。

因此，不能把 Playwright CLI 的坐标或存储状态能力假定为 Chrome MCP 后端能力，也不能绕过 snapshot ref 直接猜测元素定位。

## 文本优先与快照

页面内容以文本和可操作元素快照为主，而不是把完整 HTML 注入上下文。典型流程是：打开或导航标签页，调用 `browser_snapshot`，使用返回的 ref 执行动作，再按需截图或重新快照。浏览器工具的具体名称由 `BUILTIN_TOOL_DEFINITIONS` 中的 `browser_*` 条目和运行时注册共同决定。

## 网络策略

两个后端都通过 `BrowserSsrfGuard` 检查导航目标。默认拒绝私有地址、localhost 和其他敏感目标；Chrome MCP 额外执行主机解析 pin。该策略是浏览器出站边界，不等同于 MCP 服务器的 SSRF/allowlist，也不等同于消息频道权限。

## Profile 与并发

`ProfileManager` 将托管会话和已有 Chrome profile 分开。Chrome MCP 对同一 profile 的页面选择与操作持有 profile 锁；这属于浏览器后端内部的状态一致性约束。工具调度层的 `ConcurrencyClaim` 仍负责跨工具调用的批次并发判断，不能只根据“浏览器读取”名称推断安全并行。

## Panel 边界

26.7.25 已撤回 Panel 的 Canvas / Browser inspector seams；它们没有消费者，也不是当前浏览器工具的可用界面。现行浏览器文档只描述 `BrowserBackend`、浏览器工具、页面快照、网络策略和 profile 管理。

## 代码位置

- `src/browser/backend.rs` — 统一后端 trait
- `src/browser/manager.rs` — profile 到后端的路由
- `src/browser/playwright_cli_backend.rs` — `playwright-cli` 后端
- `src/browser/chrome_mcp_backend.rs` — Chrome DevTools MCP 后端
- `src/browser/playwright_cli.rs` — CLI 驱动
- `src/browser/chrome_mcp.rs` — Chrome MCP 驱动
- `src/browser/network_policy.rs` — 浏览器 SSRF guard
- `src/browser/profile.rs`、`src/browser/tab_registry.rs` — profile 与标签页状态
- `src/builtin_tools/browser_tools/` — 面向代理的 `browser_*` 工具
