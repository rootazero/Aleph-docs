# 术语表

本页为 Aleph 概念建立规范名称，以确保文档、代码和 UI 之间的一致性。

> **面板顶层模式**（top-level modes）：桌面面板共有七个，按导航顺序排列——Chat (`/chat`)、Dashboard (`/dashboard`)、Memory (`/memory`)、Agents (`/agents`)、Teams (`/teams`)、Extensions (`/extensions`)、Settings (`/settings`)。Settings 将 MCP / Plugins / Skills 归入 **Advanced（高级）** 组；ClawHub 设置标签页已移除。

## 核心概念

| English | 中文 | 定义 |
|---------|---------|------------|
| **Agent** | 智能体 | 具有特定配置（模型、工具、提示词）的 AI 实例 |
| **Harness** | 执行驱动 | 驱动 Agent 执行的 Think→Act 循环 |
| **Thinker** | 思考器 | LLM 交互层——提示词构建、模型路由、流式传输 |
| **Orchestrator** | 编排器 | 解析 AgentDef + FlowSpec，组装依赖，调度到 Harness |
| **Gateway** | 网关 | WebSocket 控制平面——路由、会话、事件、认证 |
| **Session** | 会话 | 由会话密钥标识的持久对话上下文 |
| **Turn** | 轮次 | 会话内的一个完整 Think→Act 循环 |
| **Flow** | 流程 | 从入口到完成的单个执行请求 |
| **FlowSpec** | 流程规范 | 定义单个流程的执行参数 |
| **AgentDef** | 智能体定义 | 定义 Agent 行为的静态配置 |

### 三对维度（用户可调）

| English | 中文 | 定义 |
|---------|---------|------------|
| **exec_tier** | 执行等级 | 决定哪些工具可被执行及如何审批；权限维度 |
| **think_level** | 思考等级 | LLM 推理预算与扩展思考开关；推理维度 |
| **session_mode** | 会话模式 | `chat` / `work` / `code` 三档，**静态分区**工具呈现面（progressive-disclosure 核心集 + deferred-tool 层级）；不影响权限 |
| **session_set_mode** | 模式切换工具 | 由模型调用的运行时模式切换工具；切回后必须被下一次 send 沿同一消息携带 |

### 治理拓扑层（loop_graph）

| English | 中文 | 定义 |
|---------|---------|------------|
| **Loop Graph** | 治理拓扑 | 叠加在 Harness 之上的治理拓扑层（`src/loop_graph/`）；给单循环的四种失败模式（Goodhart、参考盲、环冲突、测量衰减）一个拓扑答案 |
| **Team Node** | 团队节点 | 将多代理系统融合进图的节点类型——团队解散时胜利声明会触发 watcher |
| **Audit Ring** | 审计环 | 闭环审计动作日志；图审计的客观 ACL 来源 |
| **Objective ACL** | 客观 ACL | 按图节点身份客观授权的访问控制表 |
| **Victory Claim** | 胜利声明 | 团队/循环宣告完成的动作；触发 watcher 与审计 |
| **Watcher** | 观察器 | 监听治理事件（胜利声明、目标结算、团队解散）并发起审计 |
| **loop-auditor** | 循环审计员 | 内置受保护智能体；审计/监督模板默认走独立上下文证据 |
| **Goal** | 目标 | 由 GoalStore 管理的持久目标；可被循环结算触发 |
| **LoopState** | 循环状态 | `looping/` 子系统的状态机（Active/Paused/...） |
| **Pause / Resume** | 暂停 / 恢复 | 循环/目标的跨会话生命周期控制 |

## 记忆系统

| English | 中文 | 定义 |
|---------|---------|------------|
| **Memory** | 记忆系统 | 持久知识存储（SQLite + sqlite-vec + markdown 笔记） |
| **Memory Hub** | 记忆中心 | 在单一切换中同时承载图谱视图与表格视图的统一记忆面板 (`/memory`)；节点身份 == 笔记路径 |
| **Graph View** | 图谱视图 | 记忆笔记的放射状节点-连线画布（原 `/memory` 画布） |
| **Table View** | 表格视图 | 记忆笔记的分面列表（原 `/dashboard/memory` 库） |
| **Card View** | 卡片视图 | 笔记的卡片列表与批量操作栏（Vault 面板重构后的列表形态） |
| **Deep Link** | 深链 | 从卡片或证据链直接定位到对应笔记的页内锚点 |
| **Evidence Chain** | 证据链 | 引用本笔记的其他笔记序列；面板抽屉中呈现 |
| **Cross-Agent Selection** | 跨代理选择 | 跨多个代理视图的记忆选择操作，需走原子一致性 |
| **Provenance** | 来源 | 笔记/证据的来源记录（写入者、写入时间、来源事件） |
| **Batch Export** | 批量导出 | 一次性导出多张卡片为可交付物 |
| **Dream Insights** | 梦境洞察 | 只读面板（Settings > Memory），由 `dreaming.list_insights` 支撑——近期每日综合笔记 + dream-run 历史 |
| **Corrections** | 纠正记录 | 只读面板（Settings > Memory），由 `memory.list_corrections` 支撑——呈现纠正 → 蒸馏的生命周期 |
| **Raw Memory (L0)** | 原始记忆 | 压缩前的短暂会话数据 |
| **Note (L1)** | 笔记 | 持久的 markdown 知识文件 |
| **Wikilink** | 维基链接 | Obsidian 兼容的 `[[note-name]]` 交叉引用 |
| **Compression** | 压缩 | 将原始记忆转换为结构化笔记 |
| **Dream Daemon** | 梦境守护进程 | 后台记忆整合过程 |
| **Scratchpad** | 草稿板 | 每会话工作记忆（会话结束时丢弃） |
| **User Profile** | 用户画像 | 辩证用户模型 (`USER.md`) |
| **SkillOpt** | 技能优化 | 自我演化纪律——记忆侧把"够用即停"的原则落进自我演化管线 |

## 扩展

| English | 中文 | 定义 |
|---------|---------|------------|
| **Extension** | 扩展 | 面向用户的 Skill + Plugin + MCP 服务器统称——每个 Extension 恰好属于一种**类型**。参见[扩展商店](/docs/zh/concepts/extensions-store) |
| **Extensions Store** | 扩展商店 | 顶层面板模式 (`/extensions`)，按功能类别浏览/安装扩展，附带信任层级与安装前披露 |
| **ExtensionKind** | 扩展类型 | 面向商店的类型枚举 `{Skill, Plugin, Mcp}`——与插件宿主运行时的 `PluginKind {Wasm, Mcp, Static}` 不同 |
| **Aleph Hub** | Aleph Hub | 单一扩展目录源 `aleph-hub`（`hub.heyaleph.com/catalog.json`）；启动时由 `hub::primer` 投影进 `~/.aleph/hub_catalog.db` |
| **Hub 工具** | Hub 工具 | 注册在主内置工具注册表中的 `hub_catalog_sync` / `hub_fetch_docs` / `hub_resolve_spec` / `hub_install_run` / `hub_install_verify`；安装受信任与用户同意关卡约束 |
| **Trust Tier** | 信任层级 | 源的信任级别：Official / Verified / Community / Unverified |
| **Disclosure** | 披露 | 强制的安装前摘要（command+args、密钥、网络/文件系统触达、固定版本 + SHA256、层级） |
| **Source** | 源 | 目录提供方（插件市场、Official MCP Registry、Docker MCP Catalog），在 SQLite 中缓存以供离线浏览 |
| **Plugin.install (unified)** | 插件统一入口 | `plugin.install` 不再猜测来源；按源（市场 / 压缩包 / 路径）分类统一处理 |
| **Plugin Marketplace** | 插件市场 | 列入 `plugin.marketplace.list` / `plugin.marketplace.add` 的可索引目录 |

## 桌面宿主与 Panel

| English | 中文 | 定义 |
|---------|---------|------------|
| **NSH** | NSH | Aleph 桌面端的目标形态：原生桌面宿主 crate `aleph-nsh-shell`（`desktop/nsh-shell/`），基于 nsh 0.6.0（`nsh-core` / `nsh-base` / `nsh-engine` 锁定 `=0.6.0`） |
| **Desktop Host** | 桌面宿主 | 薄原生壳：只提供窗口容器、托盘、全局热键、通知、凭据存取、登录项状态读取等系统级集成；**不持有任何聊天或会话投影**（`desktop/nsh-shell/src/shell_host.rs`） |
| **Panel** | 面板 | 业务界面的唯一真值源：Rust + Leptos/WASM，代码在 `interfaces/webchat/`；NSH 托管的就是这一个 Panel，不是第二套业务 UI |
| **Panel Runtime** | 面板运行时 | Panel 内部的模块化运行时（`interfaces/webchat/src/panel/`）：`TabRegistry` / `PanelProjection` / `PanelLoader` / `PanelSdk`；`panel-modular` 是 opt-in feature |
| **Legacy Shell** | 旧桌面壳 | 过渡期遗留的 Tauri v2 应用（`desktop/shell/`）：自带 daemon supervisor、托盘、自动更新、深链、热键、菜单、通知。**最终会删除** |
| **embedded-core** | 内嵌核心 | NSH 的编译期可选特性（默认关）：本地目标且端口确实空闲时，允许启动同目录随包的 `aleph-server`；端口已被占用时只做兼容性检查，不接管已有服务 |
| **aleph:// deep link** | aleph:// 深链 | NSH 注册的 URL scheme；当前只识别精确的 `aleph://open`（打开 Chat），其余 `aleph://` URL 被忽略 |

| **Capability（扩展期）** | 能力（扩展期） | 旧扩展模型里的权限声明（文件系统 / 网络 / 进程），对应 `src/extension/` 的历史结构；现已被上述能力模型取代 |

| **SchemaRef** | 模式引用 | 能力输入输出所引用的结构契约（`src/capability/descriptor.rs`） |
| **OwnerGeneration / FencingToken** | 属主世代 / 围栏令牌 | 归属的世代号与围栏令牌：防止旧属主在回收后继续生效（`src/capability/ownership.rs`） |
| **OwnershipChange** | 归属变更 | 能力归属的变更事件 |
| **Backend / BackendLease** | 后端 / 后端租约 | 能力的实际实现来源及其租约；`BackendSourceEvidence` 记录来源证据（`src/capability/backend.rs`、`facade.rs`） |
| **PolicyDenial** | 策略拒绝 | 策略引擎拒绝一次能力调用的结果（`src/capability/policy_runtime.rs`） |
| **Zahir** | Zahir | 能力解析与分发的唯一活动宿主：`ZahirFacade`（`src/capability/zahir_facade.rs`）组合工具后端适配器（可调用工具的唯一真值源）与 `OwnershipTree`（归属 / 撤销 / 释放的唯一真值源），不持有第二套描述符或处理器表 |
| **Slot API** | 插槽 API | `crates/aleph-slot-api/`：插槽契约的唯一权威（错误、文本、工具、搜索 / 嵌入、频道、审批、取消、webhook、AI provider）。**无 I/O、无平台、无 LLM**，依赖方向单向：`alephcore → aleph-slot-api` |

## 安全

| English | 中文 | 定义 |
|---------|---------|------------|
| **Sandbox** | 沙箱 | 带有能力强制执行的每会话执行隔离 |
| **Capability（扩展期）** | 能力（扩展期） | 旧扩展模型里的权限声明（文件系统、网络、进程）；现已被 `src/capability/` 的能力模型取代，见[能力模型](/docs/zh/capabilities/capability-model) |
| **Capability Ledger** | 能力账本 | 每次安装时从磁盘重建的可见能力清单（用于安装前披露） |
| **Approval Gate** | 审批门 | 提升权限的人机回环审批 |
| **fail-closed** | 失败关闭 | 不可读或损坏的策略不静默放行：`ConfigApprovalPolicy` 回退到 Ask；缺失策略文件则使用内置的分类默认值（`src/approval/config.rs`） |
| **IdentityContext** | 身份上下文 | 流经执行的不可变身份快照 |
| **Per-Agent Signing Key** | 每代理签名密钥 | 每个 Agent 独立的签名密钥，写入操作账本 |
| **Operation Ledger** | 操作账本 | 由签名者拥有的签名操作序列 |
| **Delegated Role Chain** | 委托角色链 | 委托权限的角色链；身份链路生命周期内闭包 |
| **Signer Ownership** | 签名者所有权 | 私钥由对应的 Agent 持有，账本由签名者所属链路回放验证 |
| **PolicyEngine** | 策略引擎 | 无状态权限检查器 |
| **GuestScope** | 访客范围 | 访客会话的工具级限制 |
| **Pairing** | 配对 | 通过 PIN/代码进行设备信任建立 |
| **TOFU** | 首次使用信任 | Trust-on-First-Use：首次见到自签名证书时提示用户审批并固定指纹 + SAN |
| **SAN Drift** | SAN 漂移 | 主机非环回接口 IP 集变化；触发证书原子 regen（不破坏启动） |
| **Self-Signed TLS** | 自签名 TLS | 网关内进程终止 TLS；远程连接必须 `wss://` |
| **Trusted Proxy** | 可信代理 | 反向代理信任列表——决定网关是否读取真实客户端 IP |
| **Trusted Origin** | 可信来源 | Origin 白名单；用于浏览器与 WebView 的证书信任与麦克风权限 |
| **Guardian Judge** | 守护者判官 | heartbeat 探针使用的 LLM 判官；其 payload 必须隐藏密钥 |

## 通信

| English | 中文 | 定义 |
|---------|---------|------------|
| **Interface** | 接口 | 客户端连接类型（CLI、Telegram、Discord、iMessage 等） |
| **Channel** | 频道 | 接口内的特定对话端点 |
| **Session Key** | 会话密钥 | 会话的唯一标识符（例如 `agent:main:main`） |
| **Event Bus** | 事件总线 | 用于实时事件分发的发布/订阅系统；`broadcast::RecvError::Lagged` 必须恢复而非永久死亡 |
| **JSON-RPC** | JSON-RPC | 基于 WebSocket 的请求/响应协议 |
| **Protocol v1** | 协议 v1 | 带版本协商的新传输协议：4 字节大端长度前缀分帧 + `system.hello` 握手（`shared/protocol/src/framing.rs`、`shared/protocol/src/system_hello.rs`） |
| **Frame** | 帧 | 长度前缀 + 负载的传输单元；默认单帧上限 `DEFAULT_MAX_PAYLOAD_BYTES = 8_388_608`（8 MiB） |
| **system.hello** | system.hello | 连接建立后的握手请求：协商协议次版本与特性；major 不匹配返回 `INVALID_PARAMS` |
| **Desktop IPC** | 桌面 IPC | Unix socket 上的只读传输（`--desktop-ipc <socket>`），`src/gateway/server/connection/local_ipc.rs` |
| **Web v1** | Web v1 | 原生 TLS 的新传输：`POST /v1/session` + `GET /v1/ws`，`src/gateway/server/connection/web_v1.rs` |
| **Legacy /ws** | 旧 /ws 入口 | 无版本号的旧 WebSocket 入口（`ws://127.0.0.1:18790/ws`），不使用长度前缀分帧 |
| **Trace** | 追踪 | 用于可观察性的执行事件流 |
| **Error Receipt** | 错误回执 | 网关返回给客户端的**单一来源**用户可读错误；原始错误链不外泄 |
| **Dead Letter** | 死信 | channel.* 未能成功下发的消息，可在 Panel 内重投递 |
| **Webhook Backpressure** | Webhook 反压 | webhook 接收端在拥塞时返回 503 而不是默默丢弃 |
