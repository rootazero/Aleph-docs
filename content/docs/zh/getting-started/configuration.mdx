Aleph 默认读取 `~/.aleph/config.toml`。设置 `ALEPH_HOME` 可覆盖整个配置与数据根目录。配置值支持 `${VAR}` 和 `${VAR:-default}` 插值；只有源码明确读取的环境变量才具有额外覆盖语义。

## 文件位置

| 文件 | 用途 |
|------|------|
| `~/.aleph/config.toml` | 主配置文件 |
| `~/.aleph/defaults.toml` | 默认值覆盖 |
| `~/.aleph/config.toml.bak` | 迁移时可能创建的配置备份 |

## 最小结构

```toml
[general]
default_provider = "claude"
fallback_providers = []

[providers.claude]
provider_type = "claude"
enabled = true
api_key = "${ANTHROPIC_API_KEY}"
models = ["<当前模型目录中的模型 ID>"]

[policies]
mode = "work"
exec_tier = "auto"

[gateway]
host = "127.0.0.1"
port = 18790
```

## 提供商与模型

提供商使用 `[providers.<name>]` 表；`general.default_provider` 和 `general.fallback_providers` 引用这些名称。

```toml
[general]
default_provider = "claude"
fallback_providers = ["openai"]

[providers.claude]
provider_type = "claude"
enabled = true
api_key = "${ANTHROPIC_API_KEY}"
models = ["<Claude 模型 ID>"]

[providers.openai]
provider_type = "openai"
enabled = true
api_key = "${OPENAI_API_KEY}"
models = ["<OpenAI 模型 ID>"]
```

模型 ID 与能力会变化，应以当前模型目录和 Panel 中的提供商配置为准。

## 策略

全局会话模式与执行等级位于 `[policies]`，不在 `[agents.defaults]`：

```toml
[policies]
mode = "work"       # chat / work / code
exec_tier = "auto"  # ask / auto / full
```

| 字段 | 默认 | 作用 |
|------|------|------|
| `mode` | `work` | 静态划分工具呈现面，不改变权限 |
| `exec_tier` | `auto` | 决定工具审批策略 |

`[sandbox.command_policy]` 是独立的安全硬底，不能被 `full` 降低。思考级别默认是 `minimal`，可由会话与客户端控制；不要把不存在的 `agents.defaults.thinking` 写入配置。

## Gateway

```toml
[gateway]
host = "127.0.0.1"
port = 18790
allow_insecure_remote = false
```

WebSocket endpoint 是 `/ws`。默认完整地址为 `ws://127.0.0.1:18790/ws`。

### 原生 TLS

```toml
[gateway]
host = "0.0.0.0"
port = 18790
allow_insecure_remote = false

[gateway.tls]
enabled = true
# cert_path = "/path/to/cert.pem"
# key_path = "/path/to/key.pem"
# san = ["aleph.example.com"]
```

当 `enabled = true` 且 `cert_path`、`key_path` 为空时，核心生成并持久化自签名证书。远程客户端使用 `wss://`，Panel 首次连接通过 TOFU 审批。

### 可信反向代理

```toml
[gateway.trusted_proxy]
enabled = true
trusted_ips = ["127.0.0.1", "::1"]
```

只有来自 `trusted_ips` 的直接对端，其 `X-Forwarded-For` 与 `X-Forwarded-Proto` 才会被信任。

## Agent 默认值

`[agents.defaults]` 只包含 Agent 定义实际支持的默认值，例如模型、工作区和技能：

```toml
[agents.defaults]
model = "<模型 ID>"
workspace_root = "~/workspaces"
skills = ["search"]
```

会话模式与执行等级属于 `[policies]`，不属于此表。

## 热重载

字段是否即时生效由 `src/config/reload_impact.rs` 的分类决定。监听地址、端口和 TLS 等传输层设置通常需要重启；修改后可运行：

```bash
aleph-server doctor
aleph-server status
```

## 备份

备份整个 `ALEPH_HOME` 最稳妥。至少保留：

- `config.toml` 与 `defaults.toml`
- `data/`、`memory/` 与 `artifacts/`
- 用户安装的 `skills/` 与 `plugins/`

缓存和日志通常可重新生成，但具体目录以当前运行版本实际创建的内容为准。
