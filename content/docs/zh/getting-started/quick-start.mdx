## 桌面应用

从 [GitHub Releases](https://github.com/rootazero/Aleph/releases) 下载当前版本实际提供的安装包。不同版本和平台的产物格式可能不同，请以 Release 附件为准。

桌面壳负责窗口、托盘、通知和系统集成；推理、工具与状态由 `aleph-server` 核心提供。

## 从源码运行

从源码构建需要 Rust 1.95+。构建 Panel 或使用仓库开发任务时还需要 `just`、Node.js/npm 与 `wasm-bindgen-cli`。

```bash
git clone https://github.com/rootazero/Aleph.git
cd Aleph
just dev
```

只启动核心：

```bash
cargo run --bin aleph-server
```

Gateway 默认使用 `127.0.0.1:18790`：

- Panel：`http://127.0.0.1:18790/`
- WebSocket：`ws://127.0.0.1:18790/ws`

## 最小配置

创建 `~/.aleph/config.toml`：

```toml
[general]
default_provider = "claude"

[providers.claude]
provider_type = "claude"
enabled = true
api_key = "${ANTHROPIC_API_KEY}"
models = ["<当前模型目录中的模型 ID>"]

[policies]
mode = "work"
exec_tier = "auto"

[gateway]
host = "127.0.0.1"
port = 18790
```

```bash
export ANTHROPIC_API_KEY="sk-ant-..."
aleph-server doctor
aleph-server start
```

`mode` 默认是 `work`，只影响工具呈现；`exec_tier` 默认是 `auto`，控制审批策略。两者保持正交。

## 验证

```bash
aleph-server status
aleph-server gateway call health
```

若以 systemd 用户服务运行，可查看：

```bash
journalctl --user -u aleph-server.service -f
```

## 远程核心

在远程机器的 `~/.aleph/config.toml` 中启用非环回监听和原生 TLS：

```toml
[gateway]
host = "0.0.0.0"
port = 18790

[gateway.tls]
enabled = true
```

`cert_path` 与 `key_path` 留空时会生成自签名证书。远程 WebSocket 地址为 `wss://<host>:18790/ws`；Panel 首次连接时通过 TOFU 审批证书指纹与 SAN。
