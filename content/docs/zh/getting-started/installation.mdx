## 桌面应用

请从 [GitHub Releases](https://github.com/rootazero/Aleph/releases) 选择当前版本实际发布的平台安装包。产物格式与平台覆盖会随 Release 变化，不应假设每个版本都同时包含 `.dmg`、`.msi`、`.deb` 或 `.AppImage`。

桌面应用由薄系统壳和 `aleph-server` 核心组成。壳负责窗口、托盘、通知和平台集成；核心负责推理、工具、状态与 Gateway。

## 从源码构建

### 要求

- Rust 1.99+（以根 `Cargo.toml` 的 `rust-version` 为准）
- 平台 C/C++ 构建工具
- 使用仓库 `just` 任务时安装 `just`
- 构建 WebChat/WASM 时安装 Node.js/npm 与 `wasm-bindgen-cli`

SQLite 通过 `rusqlite` 的 bundled 功能构建，无需单独安装系统 SQLite 开发包。

### 构建核心

```bash
git clone https://github.com/rootazero/Aleph.git
cd Aleph
cargo build --bin aleph-server --release
```

产物位于 `target/release/aleph-server`。

仓库开发任务：

```bash
just deps
just dev
just check
just test
```

具体任务以当前 `Justfile` 为准。桌面壳和平台安装包需要额外的平台 SDK，并使用仓库当前的 shell 构建任务。

## 验证

```bash
aleph-server doctor
aleph-server status
```

离线检查固定 system-prompt scaffold：

```bash
aleph-server prompt-size
```

`prompt-size` 不启动 daemon、不访问网络，也不包含 identity files、memory、skills、MCP instructions 或工具 schema 等会话级内容。

## 数据根目录

Aleph 默认把配置和运行数据放在 `~/.aleph/`；`ALEPH_HOME` 可覆盖该根目录。稳定入口包括：

| 路径 | 用途 |
|------|------|
| `config.toml` | 主配置文件 |
| `defaults.toml` | 默认值覆盖 |
| `data/` | 核心数据库与运行数据 |
| `memory/` | 记忆与笔记数据 |
| `artifacts/` | 工件与交付物 |
| `skills/` | 用户技能 |
| `plugins/` | 已安装插件 |
| `logs/` | 文件日志 |

其它子目录由启用的组件按需创建，应以当前运行版本实际生成的目录为准。
