`arena.*` 命名空间在当前 `aleph-server` 运行时**未被注册**。源码中既没有 `arena` 处理模块,也没有 `registry.register("arena.*", ...)` 的调用,更不存在 `src/arena/` 模块——任何 `arena.*` 方法在运行时会返回 `Method not found`(错误码 `-32601`)。

26.7.x 的 CHANGELOG 没有关于该命名空间的条目,最初的评估竞技场设计(`src/arena/`、竞技场基准任务、排行榜)在当前构建中已不存在。

## 方法

下表所列方法在运行的 `aleph-server` 上**永远**不可达,这里仅作为历史设计的存档:

### arena.list

列出可用的评估任务和基准。

**请求:**
```json
{ "jsonrpc": "2.0", "id": 1, "method": "arena.list", "params": {} }
```

**响应:** `Method not found`(`-32601`)。

### arena.run

运行评估基准。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `benchmark_id` | string | 是 | 要运行的基准 |
| `model` | string | 条件 | 被评估的模型(仅当基准支持模型选择时) |
| `parallel` | number | 否 | 并行任务数 |

**响应:** `Method not found`(`-32601`)。

### arena.status

按 `run_id` 获取运行中评估的状态。**响应:** `Method not found`。

### arena.results

按 `run_id` 获取已完成评估的详细结果。**响应:** `Method not found`。

### arena.compare

按 `run_ids` 数组比较多次运行的结果。**响应:** `Method not found`。
