title: "plugins.*"

`plugins.*` 和规范的单数 `plugin.*` 命名空间是运行时插件宿主的两个面。两者都在 `HandlerRegistry::new()`(`src/gateway/handlers/mod.rs`)中注册,因此无论 MCP manager 是否启动都存在。

- `plugins.*` 是**遗留**命名空间,为向后兼容旧客户端保留。
- `plugin.*` 是**规范**的单数命名空间;`plugin.install` 在服务端对来源分类(市场 / git URL / 本地路径 / `.zip`)并相应路由。

日常使用中,推荐统一的 `extensions.*` 门面。`plugins.*` / `plugin.*` 是底层的插件后端(`extensions` 目录中 kind `Plugin`)。

## `plugins.*` 方法(遗留)

### plugins.list

列出所有已加载的插件及其状态。

**请求:** 无参数。

**响应:** `{ "plugins": [ ...PluginInfo... ] }`。每行包含 `name`、`version`、`description`、`enabled`、`path`、能力计数(`skills_count`、`commands_count`、`agents_count`、`hooks_count`、`mcp_servers_count`)和状态字符串 `status`(`loaded` / `disabled` / `overridden` / `error`,失败时附 `error` 字段)。

### plugins.install

从 Git URL 安装插件。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `url` | string | 是 | Git URL(`https://`、`git@` 或 `git://`);仓库名取路径最后一段,作为磁盘上的插件目录名 |

**响应:** 成功时 `{ "plugin": { ...PluginInfo... } }`;URL 派生出不安全目录名、目标已存在或验证失败时返回 `INVALID_PARAMS`;`git2::Repository::clone` 失败时返回 `INTERNAL_ERROR`。

### plugins.installFromZip

从 base64 编码的 zip 归档安装一个或多个插件。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `data` | string | 是 | base64 编码的 zip 字节 |

**响应:** `{ "installedNames": [] }`(处理函数不枚举解压出的名字,使用 `plugins.list` 刷新)。

### plugins.uninstall

卸载已加载的插件并删除其目录。**先**在运行时下线,再删除目录,这样 `services.stop` 或临时 MCP 服务器在关闭时仍能运行。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `name` | string | 是 | 插件 id(必须是单个普通路径组件——不允许 `..`、`/`) |

**响应:** `{ "ok": true }`。

### plugin.reload

对已安装插件重新加载清单和运行时,不是从任意目录首次加载。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `pluginId` | string | 是 | 已安装插件 id |

**响应:** `{ "ok": true, "pluginId", "status" }`。

重载**先预检再拆**:新版本先被解析与身份校验,WASM 插件的 guest module 先编译(不运行),此时旧版本仍在服务。预检判定新版本有缺陷且旧版本在跑时,重载就地停下,旧版本继续服务,错误文本是 `plugin '{id}' was not reloaded, the previous version is still running: {reason}`。准入被拒(操作员的决定,不是缺陷)仍然卸载旧版本并记录拒绝。预检覆盖不到的失败(链接/实例化错误、MCP server 启动、service 启动)只在挂载时出现,那时插件处于未挂载状态。

### plugins.disable（保留安装）

只需停用运行时而不删除目录时,使用 `plugins.disable`,不要调用旧的 load/unload 名称。它创建 `.disabled` 标记并拆除运行时;恢复发现使用 `plugins.enable`。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `name` | string | 是 | 插件 id |

**响应:** `{ "ok": true }`。删除安装目录则使用 `plugins.uninstall`。

### plugins.enable

移除 `.disabled` 标记文件,使插件在下次扫描时被重新发现。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `name` | string | 是 | 插件 id |

**响应:** `{ "ok": true }`。

### plugins.disable

创建 `.disabled` 标记文件并下线运行时(服务 + 临时 MCP 服务器)。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `name` | string | 是 | 插件 id |

**响应:** `{ "ok": true }`。

### plugins.callTool

调用由已加载插件注册的工具。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `pluginId` | string | 是 | 注册该工具的插件 |
| `handler` | string | 是 | 处理函数名 |
| `args` | object | 否 | 传给处理函数的 JSON 参数 |

**响应:** 成功时 `{ "result": <插件自定义 JSON> }`;若未找到 `-32001: Command not found` 或命令属于其他插件,同样返回 `-32001`。

### plugins.executeCommand

执行由插件注册的斜杠命令。处理函数在插件的 `commands/` 目录中查找命令(以 `SkillRegistration` 形式存储,`skill_type = Command`)。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `pluginId` | string | 是 | 注册该命令的插件 |
| `commandName` | string | 是 | 命令名(不带前导斜杠) |
| `args` | object | 否 | 传给处理函数的 JSON 参数 |

**响应:** 序列化为 JSON 的 `DirectCommandResult`(`content`、`data`、`success`)。

## `plugin.*` 方法(规范单数)

### plugin.list

与 `plugins.list` 相同。**响应:** `{ "plugins": [ ...PluginInfo... ] }`。

### plugin.install

统一安装入口。服务端对 `source` 分类,分派到市场安装器(裸名)或 git-clone 安装器(URL / 路径 / `git@…`)。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `source` | string | 是 | 裸名 → 市场;含有 `/`、`.` 或 `:` → git |
| `url` | string | 回退 | 旧式别名,两者都给定时以 `source` 为准 |
| `scope` | string | 否 | `user`(默认) / `project` / `local` |

**响应:** 市场路径返回 `{ "ok": true, "name", "scope", "installed_at" }`;git 路径返回与 `plugins.install` 相同的形态。

### plugin.update

原地升级已安装的插件。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `name` | string | 是 | 插件名 |
| `marketplace` | string | 否 | 消歧使用哪个市场 |
| `scope` | string | 否 | `user`(默认) / `project` / `local` |
| `force` | boolean | 否 | 即使版本未变也重装 |

**响应:** `{ "ok", "name", "scope", "updated", "from"(旧版本),"to"(新版本 | null) }`;若已是最新则返回 `{ "ok", "name", "scope", "updated": false, "version" }`。

### plugin.uninstall

与 `plugins.uninstall` 同形(旧式复数形式也可用)。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `name` | string | 是 | 插件 id |

**响应:** `{ "ok": true }`。

### plugin.enable / plugin.disable

与 `plugins.enable` / `plugins.disable` 同形。**响应:** `{ "ok": true }`。

### plugin.reload（运行时重载）

当前 census 只提供 `plugin.reload` 作为运行时重载入口;首次安装使用 `plugin.install`,停用使用 `plugins.disable`,删除使用 `plugin.uninstall`。它们不是等价操作。

| 方法 | 参数 | 说明 |
|------|------|------|
| `plugin.reload` | `pluginId` | 重新加载已安装插件;返回 `{ "ok": true, "pluginId", "status" }` |

### plugin.callTool / plugin.executeCommand

与 `plugins.callTool` / `plugins.executeCommand` 同形(`pluginId`、`handler` / `commandName`、`args`)。

### plugin.marketplace.*

市场源管理。四个方法都注册。

| 方法 | 参数 | 说明 |
|------|------|------|
| `plugin.marketplace.list` | 无 | 列出已注册市场(内置 + 用户) |
| `plugin.marketplace.add` | `source`(必填),`name`(可选) | 添加 `local` 或 `github` 市场;持久化到 `[plugin_marketplaces]` |
| `plugin.marketplace.update` | `name`(可选) | 刷新一个或所有市场的索引缓存 |
| `plugin.marketplace.remove` | `name`(必填) | 移除一个市场并持久化 |
| `plugin.marketplace.install` | `name`(必填),`marketplace`(可选),`scope`(可选) | 从具名市场安装一个插件 |
