---
title: "wizard.*"
description: "设置向导 RPC 方法"
---

`wizard.*` 是配置向导的 JSON-RPC 接口。这五个方法在 `HandlerRegistry::new()` 中以 `service_unavailable` 占位符的形式注册,在服务器启动时(`src/bin/aleph-server/commands/start/mod.rs`)通过 `install_wizard_handlers` 替换为真实处理器。运行时工厂当前只提供 `onboarding` 流;任何其它 `wizard_type` 都会从 `start` 处理函数返回 `Unknown wizard type`。

向导状态本身是进程本地的——重启守护进程会丢弃进行中的会话。已经不再有等价的 CLI 子命令(`aleph wizard` 已被删除);Panel 通过这些 RPC 驱动流程。

## 方法

### wizard.start

启动新的向导会话。返回第一步。

**请求:**
```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "wizard.start",
  "params": {
    "wizard_type": "onboarding",
    "initial_data": {}
  }
}
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `wizard_type` | string | 是 | 当前已注册的只有 `onboarding`。 |
| `initial_data` | object | 否 | 保留;运行时工厂会忽略。 |

**响应:**
```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": {
    "session_id": "<uuid>",
    "step": { "id": "...", "type": "note|select|multi_select|text|confirm|progress", ... },
    "status": "running"
  }
}
```

### wizard.next

跳过非阻塞步骤(说明/介绍)而不传答案。如果传入了 `answer`,调用会被拒绝——请改用 `wizard.answer` 提交答案。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `session_id` | string | 是 | `wizard.start` 返回的会话 id |
| `answer` | any | 否 | 保留;传入值会返回 `Invalid answer` 错误。 |

**响应:** 下一步,或终结步骤(`status: done|error|cancelled`)。

### wizard.answer

回答某一步并推进到下一步。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `session_id` | string | 是 | `wizard.start` 返回的会话 id |
| `step_id` | string | 是 | 当前正在回答的步骤 id |
| `value` | any | 是 | 答案(`text` 步骤为 string,`select` 为 string,`multi_select` 为 string[],`confirm` 为 bool) |

**响应:** 下一步,或终结步骤。

### wizard.cancel

取消一个进行中的向导会话。从管理器中移除该会话;`WizardSession` Arc 析构会关闭会话通道。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `session_id` | string | 是 | `wizard.start` 返回的会话 id |

**响应:**
```json
{ "result": { "cancelled": true } }
```

### wizard.status

获取向导会话的当前状态。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `session_id` | string | 是 | `wizard.start` 返回的会话 id |

**响应:**
```json
{ "result": { "status": "running|done|error|cancelled" } }
```

会话 id 不存在时返回 `RESOURCE_NOT_FOUND`(`-32004`)。

## 接线

`wizard.*` 处于两个阶段之间:

- `HandlerRegistry::new()`——每个 `wizard.*` 方法绑定到占位符,返回 `SERVICE_UNAVAILABLE`(`-32002`),内容为 `"wizard manager not yet initialised"`。
- `install_wizard_handlers`(在 `start_server` 中调用)——用 `src/gateway/handlers/wizard.rs` 中的真实处理器替换占位符。运行时工厂闭包到 `OnboardingFlow::new`;任何其它 `wizard_type` 会从 `start` 收到 `Unknown wizard type`。

当前运行时的 11 步入门流:provider、credentials、primary model、secondary model、thinking level、session mode、exec tier、消息应用、网关 TLS、完成步骤。状态机由 `WizardSessionManager` 和 `WizardFlow` 特征驱动,代码位于 `src/gateway/handlers/wizard.rs` 和 `src/wizard/`。
