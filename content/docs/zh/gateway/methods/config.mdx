`config.*` 提供运行时配置管理。所有方法都不要求重启网关即可生效；具体可见副作用在每条方法中说明。

## 方法

| 方法 | 说明 |
|--------|-------------|
| [`config.schema`](#configschema) | 返回完整 JSON Schema（无需参数） |
| [`config.get`](#configget) | 读取当前生效配置（含源文件路径与 mtime） |
| [`config.patch`](#configpatch) | 局部覆盖（JSON Merge Patch / RFC 7386 风格） |
| [`config.reload`](#configreload) | 从磁盘重新加载配置 |

注册于 `HandlerRegistry::new()` 但通常不通过 RPC 调用、仅供 boot 路径使用的辅助方法：

| 方法 | 说明 |
|--------|-------------|
| `config.get_full_config` | boot 路径使用的原始配置读取 |
| `config.path` | 当前配置文件绝对路径 |
| `config.validate` | 不落盘地验证配置对象 |
| `config.reload_with_subsystems` | 触发子系统热重载 |
| `config.get_tool_permissions` / `config.update_tool_permissions` | 工具权限读写 |

> `config.apply`（整配置覆盖）当前未注册；如需整配置替换请使用 `config.patch` 配合 `config.reload`。

### config.schema

返回 `~/.aleph/config.json` 的完整 JSON Schema。无参数。

**请求：**
```json
{ "jsonrpc": "2.0", "id": 1, "method": "config.schema" }
```

**响应：**
```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": {
    "schema": { "type": "object", "$schema": "...", "properties": { "...": { "...": "..." } } }
  }
}
```

### config.get

读取当前生效配置（`ConfigWatcher` 视角）。

**请求：**
```json
{ "jsonrpc": "2.0", "id": 1, "method": "config.get" }
```

**响应：**
```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": {
    "config": {
      "general": { "default_provider": "openai", "fallback_providers": [] },
      "execution": { "default_timeout_secs": 600, "max_runs_global": 16 }
    },
    "source": "/home/user/.aleph/config.json",
    "loaded_at": 1706400000000
  }
}
```

敏感字段（API 密钥、令牌）在响应中经过编辑。`source` 与 `loaded_at` 标识当前生效配置的来源与加载时间。

### config.patch

通过 JSON Merge Patch（RFC 7386 风格）应用局部覆盖。仅修改显式提供的字段；其余字段保持原值。

**请求：**
```json
{
  "jsonrpc": "2.0",
  "id": 2,
  "method": "config.patch",
  "params": {
    "patch": {
      "execution": { "max_runs_global": 32 },
      "general": { "fallback_providers": ["anthropic", "openai"] }
    }
  }
}
```

**响应：**
```json
{
  "jsonrpc": "2.0",
  "id": 2,
  "result": {
    "applied": true,
    "changed_keys": ["execution.max_runs_global", "general.fallback_providers"],
    "restart_required": false
  }
}
```

**参数：**

| 参数 | 类型 | 必填 | 说明 |
|-----------|------|----------|-------------|
| `patch` | object | 是 | Merge Patch 对象。将字段设为 `null` 可清除它 |

`restart_required` 为 `true` 时表示需要重启某接口或服务才会真正生效，并在 `restart_components` 中列出受影响组件。

### config.reload

从磁盘上的配置文件重新加载。适用于手动编辑文件或 dotfiles 仓库同步后的场景。

**请求：**
```json
{ "jsonrpc": "2.0", "id": 1, "method": "config.reload" }
```

**响应：**
```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": {
    "reloaded": true,
    "source": "/home/user/.aleph/config.json",
    "changed_keys": ["general.default_provider"],
    "restart_required": false
  }
}
```

## 热重载与可调字段

`[gateway.config_watcher]` 控制文件监视器；写盘即触发一次 reload 流程：

1. **去抖**——等待 500 ms 收尾所有写操作
2. **解析**——读取并解析新配置
3. **验证**——按 schema 校验
4. **差异**——计算变化的字段路径
5. **应用**——更新内存配置并重启受影响的接口
6. **通知**——向已订阅客户端发送 `config.changed` 事件

```json
{
  "jsonrpc": "2.0",
  "method": "event",
  "params": {
    "topic": "config.changed",
    "data": {
      "section": "execution",
      "value": { "max_runs_global": 32 },
      "timestamp": 1706400000000
    }
  }
}
```

**可热重载：** `[general]` 模型目录与故障转移链、`[providers.*]` provider 配置、channels 启停、`[execution]` 运行上限、`[cron]` 调度器设置、`[exec]` 审批规则。

**需要重启：** 核心端口、绑定地址、TLS 证书、`[memory]` 嵌入模型与向量库设置、`[browser]` CDP 设置。
