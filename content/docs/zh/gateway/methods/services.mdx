---
title: "services.*"
description: "内部服务管理 RPC 方法"
---

`services.*` 管理 Aleph 后台服务的生命周期。注册于 `HandlerRegistry::new()`（`src/gateway/handlers/mod.rs:329-332`），无外部依赖——不要求初始化即可调用。

## 方法

| 方法 | 说明 |
|--------|-------------|
| [`services.list`](#serviceslist) | 列出全部已注册服务 |
| [`services.start`](#servicesstart) | 启动一个服务 |
| [`services.stop`](#servicesstop) | 停止一个服务 |
| [`services.status`](#servicesstatus) | 读取单个服务的运行时状态 |

> `services.restart` 不是 RPC；如需重启请先 `stop` 再 `start`。

### services.list

列出全部内部服务。

**请求：**
```json
{ "jsonrpc": "2.0", "id": 1, "method": "services.list", "params": {} }
```

**响应：**
```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": {
    "services": [
      { "id": "dreaming", "name": "Dreaming", "status": "running", "healthy": true },
      { "id": "metrics", "name": "Metrics", "status": "running", "healthy": true }
    ]
  }
}
```

### services.status

读取单个服务的运行时状态（来自 `services::handle_status`）。

**请求：**
```json
{ "jsonrpc": "2.0", "id": 2, "method": "services.status", "params": { "service_id": "dreaming" } }
```

**响应：**
```json
{
  "jsonrpc": "2.0",
  "id": 2,
  "result": {
    "id": "dreaming",
    "name": "Dreaming",
    "status": "running",
    "healthy": true,
    "uptime_seconds": 3600
  }
}
```

**参数：** `service_id`（必填）。

### services.start

启动已停止的服务。

**请求：**
```json
{ "jsonrpc": "2.0", "id": 3, "method": "services.start", "params": { "service_id": "dreaming" } }
```

**响应：**
```json
{ "jsonrpc": "2.0", "id": 3, "result": { "started": "dreaming" } }
```

**参数：** `service_id`（必填）。

### services.stop

停止运行中的服务。

**请求：**
```json
{ "jsonrpc": "2.0", "id": 4, "method": "services.stop", "params": { "service_id": "dreaming" } }
```

**响应：**
```json
{ "jsonrpc": "2.0", "id": 4, "result": { "stopped": "dreaming" } }
```

**参数：** `service_id`（必填）。

## 服务状态值

| 状态 | 说明 |
|-------|-------------|
| `running` | 服务正在运行 |
| `stopped` | 服务已停止 |
| `starting` | 服务正在启动 |
| `stopping` | 服务正在停止 |
| `degraded` | 处于运行态但最近一次健康检查失败 |
