---
title: "cron.*"
description: "计划任务管理 RPC 方法"
---

`cron.*` 管理按计划触发代理提示的任务。任务由 `CronService`（位于 `src/tasks/cron/`）持久化在 SQLite 中；状态机调度取代了历史上的窗口式调度器。

## 方法

| 方法 | 说明 |
|--------|-------------|
| [`cron.list`](#cronlist) | 列出全部任务 |
| [`cron.get`](#cronget) | 获取单个任务详情 |
| [`cron.create`](#croncreate) | 新建任务 |
| [`cron.update`](#cronupdate) | 修改任务字段 |
| [`cron.delete`](#crondelete) | 删除任务 |
| [`cron.status`](#cronstatus) | 服务整体状态（运行标志 + 任务计数） |
| [`cron.run`](#cronrun) | 立即触发一次任务（绕过计划） |
| [`cron.runs`](#cronruns) | 读取任务的执行历史 |
| [`cron.toggle`](#crontoggle) | 启用 / 禁用任务 |

> 历史别名 `cron.trigger` / `cron.pause` / `cron.resume` 已并入 `cron.run` 与 `cron.toggle`；未注册独立的 pause / resume RPC。

## 计划类型（`schedule_kind`）

`cron.create` 与 `cron.update` 通过 `schedule_kind` 的 tagged 枚举选择计划类型；同时支持旧的 `"schedule": "<expr>"` 字段作为 cron 的便捷回退。

| 类型 | 字段 | 说明 |
|------|--------|-------------|
| `{ "kind": "cron", "expr": "...", "tz": "...", "stagger_ms": 0 }` | `expr`（必填） | 标准 5 字段 cron 表达式 |
| `{ "kind": "every", "every_ms": 900000 }` | `every_ms` | 固定间隔（毫秒） |
| `{ "kind": "at", "at": 1706468400000 }` | `at`（必填为未来时间戳） | 单次执行 |

`at` 计划在创建时会拒绝过去时间戳（返回 `-32602 Invalid params`）。

### cron.list

列出全部已配置任务。

**请求：**
```json
{ "jsonrpc": "2.0", "id": 1, "method": "cron.list", "params": { "limit": 50 } }
```

**响应：**
```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": {
    "jobs": [
      {
        "id": "job-uuid-123",
        "name": "Daily Summary",
        "schedule_kind": { "kind": "cron", "expr": "0 18 * * *", "tz": "America/New_York" },
        "agent_id": "main",
        "enabled": true,
        "next_run_at_ms": 1706468400000,
        "last_run_at_ms": 1706382000000,
        "tags": ["productivity"]
      }
    ]
  }
}
```

**参数：** `limit`（number，可选，默认 50）。

### cron.get

读取单个任务的完整视图。

**请求：**
```json
{ "jsonrpc": "2.0", "id": 2, "method": "cron.get", "params": { "job_id": "job-uuid-123" } }
```

**响应：**
```json
{
  "jsonrpc": "2.0",
  "id": 2,
  "result": {
    "job": {
      "id": "job-uuid-123",
      "name": "Daily Summary",
      "agent_id": "main",
      "prompt": "Summarize today's activities",
      "enabled": true,
      "schedule_kind": { "kind": "cron", "expr": "0 18 * * *" },
      "tags": ["productivity"],
      "session_target": "ephemeral",
      "timeout_ms": 600000,
      "next_run_at_ms": 1706468400000,
      "last_run_at_ms": 1706382000000
    }
  }
}
```

### cron.create

创建任务。必填字段为 `name`；`agent_id` 默认 `"main"`；`prompt` 默认空串；`schedule_kind` 或回退字段 `"schedule"` 二者必须提供其一。

**请求：**
```json
{
  "jsonrpc": "2.0",
  "id": 3,
  "method": "cron.create",
  "params": {
    "name": "Daily Summary",
    "schedule_kind": { "kind": "cron", "expr": "0 18 * * *", "tz": "America/New_York" },
    "agent_id": "main",
    "prompt": "Summarize today's activities",
    "enabled": true,
    "tags": ["productivity", "daily"],
    "timezone": "America/New_York",
    "timeout_ms": 600000,
    "session_target": "ephemeral"
  }
}
```

**响应：**
```json
{
  "jsonrpc": "2.0",
  "id": 3,
  "result": {
    "job": {
      "id": "job-uuid-123",
      "name": "Daily Summary",
      "enabled": true,
      "schedule_kind": { "kind": "cron", "expr": "0 18 * * *", "tz": "America/New_York" }
    }
  }
}
```

**参数：**

| 参数 | 类型 | 必填 | 说明 |
|-----------|------|----------|-------------|
| `name` | string | 是 | 任务名称 |
| `schedule_kind` | object | 是* | tagged 计划枚举（cron / every / at） |
| `schedule` | string | 否 | `schedule_kind` 缺省时的便捷回退，仅作为 cron 表达式 |
| `agent_id` | string | 否 | 默认 `"main"` |
| `prompt` | string | 否 | 默认空串 |
| `enabled` | boolean | 否 | 默认 `true` |
| `tags` | string[] | 否 | 任务标签 |
| `timezone` | string | 否 | IANA 时区，仅在 cron 计划时使用 |
| `timeout_ms` | number | 否 | 正整数（毫秒），`null` 保留默认 |
| `session_target` | object | 否 | 会话目标（main / ephemeral 等） |

### cron.update

局部修改任务字段。`timeout_ms` 字段三态：缺省 = 不动、`null` = 清除、正整数 = 设置。负数 / 0 / 非整型会被拒绝。

**请求：**
```json
{
  "jsonrpc": "2.0",
  "id": 4,
  "method": "cron.update",
  "params": {
    "job_id": "job-uuid-123",
    "enabled": false,
    "prompt": "New prompt text",
    "schedule_kind": { "kind": "every", "every_ms": 900000 },
    "timeout_ms": 900000
  }
}
```

**响应：**
```json
{ "jsonrpc": "2.0", "id": 4, "result": { "job": { "id": "job-uuid-123", "enabled": false } } }
```

### cron.delete

删除任务。

**请求：**
```json
{ "jsonrpc": "2.0", "id": 5, "method": "cron.delete", "params": { "job_id": "job-uuid-123" } }
```

**响应：**
```json
{ "jsonrpc": "2.0", "id": 5, "result": { "deleted": "job-uuid-123" } }
```

### cron.status

服务整体状态（与单任务状态无关）。

**响应：**
```json
{
  "jsonrpc": "2.0",
  "id": 6,
  "result": {
    "running": true,
    "job_count": 7,
    "enabled_count": 5
  }
}
```

### cron.run

立即触发任务执行（绕过计划）。内部委托 `CronService::run_job`：会校验任务已启用、未在运行中，且持久化下一次触发；持久化失败会被传播为错误（不会出现"成功响应但任务从未真正运行"的情况），并触发 `cron.job.changed` 事件。

**请求：**
```json
{ "jsonrpc": "2.0", "id": 7, "method": "cron.run", "params": { "job_id": "job-uuid-123" } }
```

**响应：**
```json
{
  "jsonrpc": "2.0",
  "id": 7,
  "result": {
    "triggered": "job-uuid-123",
    "status": "queued",
    "next_run_at_ms": 1706400000000
  }
}
```

### cron.runs

读取任务的执行历史（来自 SQLite 持久化层）。

**请求：**
```json
{ "jsonrpc": "2.0", "id": 8, "method": "cron.runs", "params": { "job_id": "job-uuid-123", "limit": 20 } }
```

**响应：**
```json
{
  "jsonrpc": "2.0",
  "id": 8,
  "result": {
    "runs": [
      {
        "run_id": "run-uuid-001",
        "started_at_ms": 1706382000000,
        "ended_at_ms": 1706382015000,
        "duration_ms": 15000,
        "status": "completed",
        "trigger_source": "schedule"
      }
    ]
  }
}
```

**参数：** `job_id`（必填）、`limit`（可选，默认 20）。

### cron.toggle

切换启用状态。

**请求：**
```json
{ "jsonrpc": "2.0", "id": 9, "method": "cron.toggle", "params": { "job_id": "job-uuid-123" } }
```

**响应：**
```json
{ "jsonrpc": "2.0", "id": 9, "result": { "job": { "id": "job-uuid-123", "enabled": true } } }
```

## 运行状态值

| 状态 | 说明 |
|--------|-------------|
| `queued` | 已入队，等待执行 |
| `running` | 正在执行 |
| `completed` | 成功完成 |
| `failed` | 执行失败 |
| `retrying` | 失败，正在重试 |

## 事件

调度器在任务状态变化时通过总线发送 `cron.job.changed` 事件；面板订阅此主题以实时刷新。
