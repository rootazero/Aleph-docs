代理方法控制 Aleph 核心 AI 执行循环（Think→Act 工具链）。`agent.*` 是面板和外部集成直接调用的入口；面向聊天的客户端通常使用 [`chat.*`](./chat) 系列，二者在底座复用同一执行适配器。

## 方法

| 方法 | 说明 |
|--------|-------------|
| [`agent.run`](#agentrun) | 启动一次 run（异步，立即返回 `run_id`） |
| [`agent.status`](#agentstatus) | 按 `run_id` 轮询 run 状态 |
| [`agent.cancel`](#agentcancel) | 取消一个进行中的 run |
| [`agent.list`](#agentlist) | 列出路由器中已注册的代理 |

> 历史别名 `agent.history` / `agent.clear` / `agent.respondToInput` / `agent.events` 等不是 RPC；会话读取请用 `chat.history` / `chat.clear`，事件订阅请用 [`events.*`](./events)。

### agent.run

启动一次代理 run，立即返回 `run_id`；实际响应通过事件流投递（`stream.*` 与 `agent.*` 主题）。

**请求：**
```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "agent.run",
  "params": {
    "input": "Summarize today's news",
    "session_key": "agent:main:main",
    "thinking": "medium"
  }
}
```

**响应：**
```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": {
    "run_id": "run-uuid-123",
    "session_key": "agent:main:main",
    "accepted_at": "2026-03-15T10:00:00Z"
  }
}
```

**参数：**

| 参数 | 类型 | 必填 | 说明 |
|-----------|------|----------|-------------|
| `input` | string | 是 | 用户输入；不可为空 |
| `session_key` | string | 否 | 会话键，自动派生 |
| `channel` | string | 否 | 通道标识（如 `"cli:term1"`） |
| `peer_id` | string | 否 | 按 peer 隔离会话时使用 |
| `stream` | boolean | 否 | 是否流式事件，默认 `true` |
| `thinking` | string | 否 | 推理深度：`off` / `minimal` / `low` / `medium` / `high` / `xhigh`（默认 `minimal`） |
| `attachments` | object[] | 否 | 文件附件（`name` / `mime_type` / base64 `data`） |
| `agent_id` | string | 否 | 显式目标代理，跳过通道绑定 |
| `project_root` | string | 否 | 项目根目录，覆盖默认工作区 |
| `model_override` | object | 否 | 临时模型覆盖（见 [`model_override`](./chat#chat-send)） |
| `exec_tier` | string | 否 | 执行等级，首次会话时由 composer 决定 |
| `mode` | string | 否 | 会话模式：`chat` / `work` / `code` |
| `voice_input` | boolean | 否 | 标记本轮为语音转写输入 |

**响应字段：**

| 字段 | 说明 |
|--------|-------------|
| `run_id` | 唯一 run 标识，配合 `agent.status` / `agent.cancel` 使用 |
| `session_key` | 解析后的会话键 |
| `accepted_at` | RFC3339 UTC 时间戳 |

### agent.status

按 `run_id` 查询当前 run 的运行态。

**请求：**
```json
{
  "jsonrpc": "2.0",
  "id": 2,
  "method": "agent.status",
  "params": { "run_id": "run-uuid-123" }
}
```

**响应：**
```json
{
  "jsonrpc": "2.0",
  "id": 2,
  "result": {
    "run_id": "run-uuid-123",
    "session_key": "agent:main:main",
    "status": "running",
    "elapsed_ms": 1247
  }
}
```

`status` 取值为 `running` / `completed` / `failed` / `cancelled`。未找到 `run_id` 时返回 `-32602 Invalid params`。

### agent.cancel

取消一个进行中的 run。取消令牌传递到执行适配器；run 在下一个安全检查点停止并释放资源。

**请求：**
```json
{
  "jsonrpc": "2.0",
  "id": 3,
  "method": "agent.cancel",
  "params": { "run_id": "run-uuid-123" }
}
```

**响应：**
```json
{ "jsonrpc": "2.0", "id": 3, "result": { "run_id": "run-uuid-123", "cancelled": true } }
```

`cancelled` 表示取消请求已被接受；run 真正停止前的过渡态由 `agent.status` 返回。

### agent.list

列出路由器中已注册的全部代理（来自 `AgentRouter`），并返回当前默认代理。

**请求：**
```json
{ "jsonrpc": "2.0", "id": 4, "method": "agent.list" }
```

**响应：**
```json
{
  "jsonrpc": "2.0",
  "id": 4,
  "result": {
    "agents": [
      { "id": "main", "name": "Main", "enabled": true, "is_default": true }
    ],
    "default": "main"
  }
}
```

每个条目字段：`id` / `name` / `enabled` / `is_default`（按 `AgentRouter::list_agents` 实际返回）。

## 流式事件

`agent.run` 启动后，事件总线以 WebSocket 通知形式投递运行状态变更（具体主题由 `GatewayEventFrame::topic_name()` 输出）：

| 主题 | 说明 |
|-------|-------------|
| `run.accepted` | run 已入队并启动 |
| `agent.reasoning` | 思考阶段输出 |
| `agent.reasoning.block` | 推理块（双过程认知） |
| `agent.tool.start` | 工具调用开始 |
| `agent.tool.update` | 工具进度更新 |
| `agent.tool.end` | 工具调用结束 |
| `agent.trace` | 执行轨迹事件 |
| `agent.response.chunk` | 响应文本块 |
| `agent.context.gauge` | 上下文窗口使用率 |
| `agent.run.complete` | run 成功完成 |
| `agent.run.error` | run 出错 |
| `agent.run.retrying` | 失败重试 |
| `agent.ask.user` | `ask_user` 触发澄清 |
| `agent.clarification.ended` | 澄清回合结束 |
| `agent.uncertainty` | 模型不确定性信号 |
| `agent.model.resolved` | 模型选择已解析 |

非流式事件同样沿同一总线：

| 主题 | 说明 |
|-------|-------------|
| `session.updated` / `session.lifecycle.changed` | 会话变更 |
| `running.set.changed` | 活跃 run 集合变化 |
| `channel.message` / `channel.typing` / `channel.status` / `channel.error` | 通道事件 |
| `config.changed` | 配置变更 |
| `approval.requested` / `approval.resolved` / `approval.expired` | 审批请求 |
| `cron.job.changed` / `heartbeat.task.changed` | 调度任务变更 |
| `team.changed` | 团队变更 |
| `acp.sessions.changed` | ACP 会话变更 |
| `gateway.token.rotated` / `gateway.device.revoked` | 网关凭据事件 |
| `surface.notify` / `surface.approval` | 面板通知 |
| `runtimes.install.progress` | 运行时安装进度 |

## 会话键格式

代理方法接受 `session_key` 参数决定上下文隔离。详见[协议](../protocol)页面。

| 格式 | 示例 | 说明 |
|--------|---------|-------------|
| Main | `agent:main:main` | 跨通道共享会话 |
| DM | `agent:main:telegram:dm:user123` | 每用户直接消息 |
| Group | `agent:main:discord:group:guild-id` | 群组/频道聊天 |
| Task | `agent:main:cron:daily-summary` | 计划任务或 webhook 任务 |
| Ephemeral | `agent:main:ephemeral:uuid` | 临时会话，不持久化 |

## 思考级别

`thinking` 参数控制代理响应前的推理深度。

| 级别 | 用例 |
|-------|---------|
| `off` | 快速直接回答 |
| `minimal` | 简单查询（默认） |
| `low` | 标准对话 |
| `medium` | 复杂任务 |
| `high` | 多步推理 |
| `xhigh` | 深度分析 |
