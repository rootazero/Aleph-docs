title: "mcp.*"
description: "MCP 服务器管理 RPC 方法"

`mcp.*` 是 MCP 插件宿主的运行时接口。处理模块位于 `src/gateway/handlers/mcp.rs`,九个核心方法通过 `register_mcp_handlers` 在 `McpManagerActor` 启动后连接。在模拟模式(没有 MCP actor)中,命名空间不存在,任何 `mcp.*` 调用返回 `Method not found`。三个审批方法在 `HandlerRegistry::new()` 中以 stub 形式直接注册——它们当前只记录日志并返回成功。

`mcp_config.*` 是 MCP 服务器的设置页 CRUD 接口;它与运行时方法并列注册,仅在 MCP manager 存在时连接。

## 方法

### mcp.list

列出所有已配置的 MCP 服务器及其实时状态(id、name、transport、status、healthy、tools/resources/prompts 计数)。

**请求:** 无参数。

**响应:** `{ "servers": [ ...ServerInfo... ] }`。每个 `ServerInfo` 包含来自 MCP actor 的实时 `pid`、`uptime_seconds` 和 `restart_count`。

### mcp_config.create

新增 MCP 服务器配置。参数与处理逻辑见 `src/gateway/handlers/mcp_config.rs`。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `name` | string | 是 | 显示名，用于派生服务器 id；重复 id 被拒绝 |
| `config` | object | 是 | `McpServerConfigJson`，见 [Config 字段](#config-字段) |

**响应:** 成功时 `{ "ok": true }`。

### mcp_config.update

更新已有服务器并重启。参数与处理逻辑见 `src/gateway/handlers/mcp_config.rs`。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `id` | string | 是 | 已有服务器 id |
| `config` | object | 是 | `McpServerConfigJson` |

**响应:** 成功时 `{ "ok": true }`。

### mcp.delete

删除 MCP 服务器配置。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `id` | string | 是 | 服务器 id |

**响应:** `{ "ok": true }`。

### mcp.status

获取单个 MCP 服务器的详细状态,包括实时 `pid`、`uptime_seconds` 和 `restart_count`。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `id` | string | 是 | 服务器 id |

**响应:** 完整的 `ServerStatus` 对象,或 `RESOURCE_NOT_FOUND`(`-32004`)。

### mcp.logs

获取一个服务器的最近日志。MCP actor **不**保留日志缓冲;此处理函数返回空列表加 `implemented: false`,让客户端能区分"无日志"与"实现缺失"。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `id` | string | 是 | 服务器 id |
| `max_lines` | number | 否 | 默认为 100 |

**响应:** `{ "logs": [], "implemented": false }`。

### mcp.start

启动已停止的 MCP 服务器。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `id` | string | 是 | 服务器 id |

**响应:** `{ "ok": true }`。

### mcp.stop

停止运行中的 MCP 服务器。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `id` | string | 是 | 服务器 id |

**响应:** `{ "ok": true }`。

### mcp.restart

停止再启动 MCP 服务器。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `id` | string | 是 | 服务器 id |

**响应:** `{ "ok": true }`。

### mcp.tools

列出所有健康 MCP 服务器对外公布的工具(聚合视图)。**请求:** 无参数。**响应:** `{ "tools": [ ...Tool... ] }`。每行包含 `name`、`description`、`server`。

### mcp.resources

列出所有健康 MCP 服务器对外公布的资源。**响应:** `{ "resources": [ ...Resource... ] }`。

### mcp.prompts

列出所有健康 MCP 服务器对外公布的 prompts。**响应:** `{ "prompts": [ ...Prompt... ] }`。

### mcp.list_pending_approvals

列出所有等待用户响应的审批请求。Stub 实现;返回空数组,因为审批处理函数尚未接入。在 `HandlerRegistry::new()` 中直接注册,因此无论 MCP actor 是否启动,始终存在。

**响应:** `{ "result": [] }`。

### mcp.respond_approval

提交用户对审批请求的响应。Stub 实现;只记录日志并返回成功。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `request_id` | string | 是 | 审批请求 id |
| `approved` | boolean | 是 | 用户是否批准 |
| `reason` | string | 否 | 自由文本原因 |

**响应:** `{ "success": true }`。

### mcp.cancel_approval

取消待处理的审批请求。Stub 实现;只记录日志并返回成功。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `request_id` | string | 是 | 审批请求 id |

**响应:** `{ "success": true }`。

## Config 字段

`mcp_config.create` 与 `mcp_config.update` 的 `config` 参数是 `McpServerConfigJson`，定义见 `src/gateway/handlers/mcp_config.rs`。

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `command` | string | 是 | stdio 命令 |
| `args` | string[] | 否 | 命令参数，默认空 |
| `env` | object | 否 | 环境变量；敏感值写入 vault |
| `cwd` | string | 否 | 工作目录 |
| `requires_runtime` | string | 否 | 所需运行时 |
| `timeout_seconds` | number | 否 | 请求超时秒数 |
| `enabled` | boolean | 否 | 创建时默认 true |

## `mcp_config.*`(设置页 CRUD)

`mcp_config.*` 是设置页的配套。它在 `register_mcp_config_handlers` 中与运行时方法一同注册。

| 方法 | 用途 |
|------|------|
| `mcp_config.list` | 列出 MCP 服务器配置行(持久化形态,非实时状态) |
| `mcp_config.get` | 按 id 获取单个配置行 |
| `mcp_config.create` | 新增配置行,API 密钥入 vault |
| `mcp_config.update` | 更新配置行 |
| `mcp_config.delete` | 删除配置行 |

设置页通过 `mcp_config.*` 编辑;运行时的 `mcp.*` 接口反映最终的实时状态。
