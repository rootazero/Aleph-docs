`logs.*` 暴露日志级别控制与日志目录查询三个方法。所有方法都基于 `RUST_LOG` 风格的过滤字符串（`error` / `warn` / `info` / `debug` / `trace`），由 `src/logging/` 提供底层支持。

## 方法

| 方法 | 说明 |
|--------|-------------|
| [`logs.getLevel`](#logsgetlevel) | 读取当前全局日志级别 |
| [`logs.setLevel`](#logssetlevel) | 设置全局日志级别 |
| [`logs.getDirectory`](#logsgetdirectory) | 返回日志目录绝对路径 |

> 历史别名 `logs.list` / `logs.get` / `logs.tail` / `logs.levels` / `logs.set_level` 不是 RPC；运行时只暴露以上三个端点。

### logs.getLevel

读取当前进程级日志级别（来自 `crate::logging::get_log_level()`）。

**请求：**
```json
{ "jsonrpc": "2.0", "id": 1, "method": "logs.getLevel" }
```

**响应：**
```json
{ "jsonrpc": "2.0", "id": 1, "result": { "level": "info" } }
```

`level` 字段返回 `LogLevel::to_filter_string()` 的输出，取值范围 `error` / `warn` / `info` / `debug` / `trace`。

### logs.setLevel

设置全局日志级别，立即生效。

**请求：**
```json
{ "jsonrpc": "2.0", "id": 2, "method": "logs.setLevel", "params": { "level": "debug" } }
```

**响应：**
```json
{ "jsonrpc": "2.0", "id": 2, "result": { "ok": true, "level": "debug" } }
```

**参数：**

| 参数 | 类型 | 必填 | 说明 |
|-----------|------|----------|-------------|
| `level` | string | 是 | `error` / `warn` / `info` / `debug` / `trace` |

非法值返回 `-32602 Invalid params` 并列出有效集合。

### logs.getDirectory

返回日志目录的绝对路径。该目录由 `crate::logging::get_log_directory()` 解析；日志文件按 `aleph-<service>.log.<date>` 命名并按 day-boundary 滚动（启动时写入 `ALEPH-BOOT` marker）。

**请求：**
```json
{ "jsonrpc": "2.0", "id": 3, "method": "logs.getDirectory" }
```

**响应：**
```json
{ "jsonrpc": "2.0", "id": 3, "result": { "directory": "/home/user/.aleph/logs" } }
```

读取目录内文件请使用 [`daemon.logs`](./daemon#daemonlogs)。
