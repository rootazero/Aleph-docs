`events.*` 管理 WebSocket 连接上的实时事件订阅。所有事件都通过同一个主题总线投递（`src/gateway/event_bus.rs`），并由 `SubscriptionManager` 按连接维护订阅。

## 方法

| 方法 | 说明 |
|--------|-------------|
| [`events.subscribe`](#eventssubscribe) | 添加主题订阅（累加） |
| [`events.unsubscribe`](#eventsunsubscribe) | 移除主题订阅 |
| [`events.list`](#eventslist) | 列出当前连接的活动订阅 |

## 事件传递

事件以 WebSocket 上的 JSON-RPC 通知（无 `id` 字段）形式投递，结构由 `TopicEvent` 序列化：

```json
{
  "jsonrpc": "2.0",
  "method": "event",
  "params": {
    "topic": "agent.run.complete",
    "data": { "run_id": "run-uuid-123", "duration_ms": 5000 },
    "timestamp": 1706400000000
  }
}
```

事件为即发即弃：服务器推送，不等待确认；客户端断连期间的事件会丢失。每条事件主题名由 `GatewayEventFrame::topic_name()` 返回，详见[事件主题](#事件主题)。

### events.subscribe

订阅一个或多个主题。订阅是**累加的**——多次调用会持续追加模式，不影响已有订阅。

**请求（仅模式）：**
```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "events.subscribe",
  "params": {
    "topics": ["agent.run.*", "session.*"]
  }
}
```

**请求（带字段过滤）：**
```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "events.subscribe",
  "params": {
    "topics": [
      "agent.run.*",
      { "topic": "tools.changed", "where": [{ "field": "scope", "equals": "extension" }] }
    ]
  }
}
```

**响应：**
```json
{ "jsonrpc": "2.0", "id": 1, "result": { "subscribed": ["agent.run.*", "session.*"], "changed": 2 } }
```

**参数：**

| 参数 | 类型 | 必填 | 说明 |
|-----------|------|----------|-------------|
| `topics` | array | 是 | 主题选择器数组；每个元素为字符串模式或 `{topic, where}` 过滤对象 |

`where` 子句中的每个谓词为 `{ "field": "<json_pointer>", "equals": <value> }`；payload 中对应字段必须严格等于给定值才会投递。无 payload 时带谓词的订阅会被跳过（不会盲目放行）。

### events.unsubscribe

按精确匹配移除模式。模式必须与已订阅的形式完全一致才会被移除。

**请求：**
```json
{
  "jsonrpc": "2.0",
  "id": 2,
  "method": "events.unsubscribe",
  "params": { "topics": ["agent.run.*"] }
}
```

**响应：**
```json
{ "jsonrpc": "2.0", "id": 2, "result": { "subscribed": ["session.*"], "changed": 1 } }
```

### events.list

列出当前连接的全部已订阅模式。

**请求：**
```json
{ "jsonrpc": "2.0", "id": 3, "method": "events.list" }
```

**响应：**
```json
{ "jsonrpc": "2.0", "id": 3, "result": { "subscribed": ["session.*"] } }
```

## 事件主题

主题空间按命名空间分组；同一组事件可能在 `events.subscribe` 中用通配 `*` 一并订阅。

### Run / Agent 生命周期（`run.*`、`agent.*`）

| 主题 | 说明 |
|-------|-------------|
| `run.accepted` | run 已入队并启动 |
| `agent.reasoning` | 思考阶段输出 |
| `agent.reasoning.block` | 推理块（双过程认知） |
| `agent.tool.start` | 工具调用开始 |
| `agent.tool.update` | 工具进度更新 |
| `agent.tool.end` | 工具调用结束 |
| `agent.trace` | 执行轨迹事件 |
| `agent.response.chunk` | 响应文本块 |
| `agent.context.gauge` | 上下文窗口使用率 |
| `agent.run.complete` | run 成功完成 |
| `agent.run.error` | run 出错 |
| `agent.run.retrying` | 失败重试 |
| `agent.ask.user` | `ask_user` 触发澄清 |
| `agent.clarification.ended` | 澄清回合结束 |
| `agent.uncertainty` | 模型不确定性信号 |
| `agent.model.resolved` | 模型选择已解析 |

### Session / Running Set

| 主题 | 说明 |
|-------|-------------|
| `session.updated` | 会话元数据更新 |
| `session.lifecycle.changed` | 会话生命周期阶段变化 |
| `running.set.changed` | 活跃 run 集合变化 |

### Channels

| 主题 | 说明 |
|-------|-------------|
| `channel.message` | 入站消息 |
| `channel.typing` | 输入指示器 |
| `channel.status` | 通道运行状态 |
| `channel.error` | 通道错误 |

### Config / Approvals

| 主题 | 说明 |
|-------|-------------|
| `config.changed` | 配置变更（来自 `[gateway.config_watcher]` 热重载或 RPC） |
| `approval.requested` / `approval.resolved` / `approval.expired` | 审批生命周期 |

### Cron / Heartbeat

| 主题 | 说明 |
|-------|-------------|
| `cron.job.changed` | cron 任务变更（含 `cron.run` 触发） |
| `heartbeat.task.changed` | 心跳任务变更 |

### Teams / ACP / Gateway 凭据

| 主题 | 说明 |
|-------|-------------|
| `team.changed` | 团队组成或任务变更 |
| `acp.sessions.changed` | ACP 会话集合变化 |
| `gateway.token.rotated` | 网关 token 轮换 |
| `gateway.device.revoked` | 设备撤销 |

### Surfaces / Runtimes

| 主题 | 说明 |
|-------|-------------|
| `surface.notify` | 面板通用通知 |
| `surface.approval` | 面板审批请求 |
| `runtimes.install.progress` | 运行时安装进度（步骤 / 日志 / 完成 / 失败） |

## Glob 模式匹配

订阅模式使用 glob 风格匹配（`src/gateway/event_bus.rs::topic_matches`）：

| 模式 | 匹配 |
|---------|---------|
| `agent.run.*` | `agent.run.started`、`agent.run.complete` 等 |
| `agent.*` | 所有 `agent.` 前缀的事件 |
| `*` | 所有事件 |
| `agent.run.complete` | 仅精确匹配 |
| `*.complete` | 任何以 `.complete` 结尾的事件 |

`*` 通配符匹配单个非点段；模式按完整主题字符串匹配。

## 典型客户端流程

```json
// 1. 订阅相关主题
{ "jsonrpc": "2.0", "id": 1, "method": "events.subscribe", "params": { "topics": ["agent.*", "session.*"] } }

// 2. 启动一次 run
{ "jsonrpc": "2.0", "id": 2, "method": "agent.run", "params": { "input": "Check disk usage" } }

// 3. 接收事件（无 id = 通知）
{ "jsonrpc": "2.0", "method": "event", "params": { "topic": "run.accepted", "data": { "run_id": "run-123" } } }
{ "jsonrpc": "2.0", "method": "event", "params": { "topic": "agent.response.chunk", "data": { "run_id": "run-123", "content": "Disk usage is at 45%..." } } }
{ "jsonrpc": "2.0", "method": "event", "params": { "topic": "agent.run.complete", "data": { "run_id": "run-123", "duration_ms": 4200 } } }
```
