本页用于查找 Gateway 方法名、角色分类与已有分册。

## 方法册是什么

`src/gateway/method_census.rs` 的 `RPC_METHOD_CENSUS` 是测试中的静态审计表，不是运行期发现接口：它逐项记录注册方法与 `Class::Open` / `Class::Admin`，并用测试比对注册点与运行期判定。下列全部方法名及分类直接取自该表；用途列只解释名称，不替代参数与行为契约。运行期分类权威是 `src/gateway/method_admin.rs`。

## 命名空间

索引按代码中实际存在的首段前缀分组。`agent` / `agents`、`session` / `sessions`、`channel` / `channels` 是不同前缀，不合并成虚构方法名。无点号的方法单列。来源：`src/gateway/method_census.rs`。

## Open 与 Admin

`Open` 表示角色门控不要求 operator，并不免除认证、会话所有权、资源策略或传输入口限制；`Admin` 要求 operator。已认证 member 调用 Admin 方法时返回 `AUTH_REQUIRED`（-32000）及下列消息。见 `src/gateway/method_admin.rs`、`src/gateway/server/connection/dispatch.rs` 与 `shared/protocol/src/jsonrpc.rs`。

```text
Not authorized: this method requires operator privileges
```

本地核对某个方法时，在代码仓查表及判定函数，例如：

```bash
rg -n '"chat.send"' src/gateway/method_census.rs
rg -n 'method_requires_admin|MEMBER_CARVE_OUTS|ADMIN_PREFIXES' src/gateway/method_admin.rs
```
