Aleph 网关通过命名空间的 JSON-RPC 2.0 方法暴露其功能。每个命名空间对相关操作进行分组，每个方法都遵循相同的请求 / 响应约定。命名空间注册位置见 [`src/gateway/handlers/mod.rs`](../../../reference/GATEWAY.md) 与 `src/bin/aleph-server/commands/start/builder/handlers/` 下的 boot 路径。

## 请求格式

所有 RPC 请求都使用 JSON-RPC 2.0 信封：

```json
{
  "jsonrpc": "2.0",
  "id": "unique-id",
  "method": "namespace.method",
  "params": { ... }
}
```

- `id` 可以是字符串、数字或 `null`（`null` 表示通知）
- `method` 遵循 `namespace.action` 命名约定
- `params` 是每个方法的可选 JSON 对象

## 响应格式

**成功：**
```json
{
  "jsonrpc": "2.0",
  "id": "unique-id",
  "result": { ... }
}
```

**错误：**
```json
{
  "jsonrpc": "2.0",
  "id": "unique-id",
  "error": {
    "code": -32601,
    "message": "Method not found",
    "data": null
  }
}
```

## 错误代码

| 代码 | 名称 | 说明 |
|------|------|-------------|
| -32700 | Parse error | 格式错误的 JSON |
| -32600 | Invalid Request | 缺少必填字段 |
| -32601 | Method not found | 未知方法名 |
| -32602 | Invalid params | 错误或缺少参数 |
| -32603 | Internal error | 服务器端故障 |
| -32000 | Auth required | 未提供凭据 |
| -32001 | Auth failed | 令牌或签名无效 |
| -32002 | Permission denied | 权限不足 |
| -32003 | Rate limited | 请求过多 |
| -32004 | Resource not found | 请求的实体不存在 |
| -32005 | Timeout | 操作超时 |
| -32006 | Tool error | 工具执行失败 |

## 占位符与状态码

`HandlerRegistry::new()` 在 `src/gateway/handlers/mod.rs` 中预注册一组方法以保证 `METHOD_NOT_FOUND` 的确定性：

- **已就绪**——`health` / `echo` / `version` / `system.info` / `request.state` / `config.schema` / `logs.getLevel` / `logs.setLevel` / `logs.getDirectory` / `services.*` / `pty.*` / `plugins.*` / `plugin.*` / `hooks.*` / `mcp.list_pending_approvals` / `mcp.respond_approval` / `mcp.cancel_approval` / `skills.*` / `bundled.sync` / `daemon.logs`
- **Stub（待 boot 路径覆盖）**——`cron.*` / `heartbeat.*` / `chat.send` / `chat.abort` / `chat.history` / `chat.clear` / `session.usage` / `session.compact` / `session.truncate` / `workspace.*` / `channels.set_agent` / `agents.bindings` / `groups_*` / `daemon.status` / `daemon.shutdown` / `teams.*` / `agents.*` / `runtimes.*` / `tools.*` / `insights.tools` / `gateway.identity.get` / `gateway.metrics.*` / `gateway.credentials` / `trace.*` / `wizard.*`
- **未注册（METHOD_NOT_FOUND）**——`identity.get` / `identity.set` / `identity.clear` / `identity.list`（必须经 `register_identity_handlers` 注入）；`graph.*`（必须经 `register_graph_handlers` 注入）

Stub 在启动后的第一个请求前由 `register_*_handlers`（`src/bin/aleph-server/commands/start/builder/handlers/`）覆盖。

## 常见模式

### 分页

返回列表的方法接受可选的 `limit` 与 `offset` 参数（实现因方法而异；详见各子页面）：

```json
{ "jsonrpc": "2.0", "id": 1, "method": "cron.list", "params": { "limit": 20, "offset": 0 } }
```

### 流式事件

`agent.run` 与 `chat.send` 触发 `stream.*` 与 `agent.*` 主题事件。订阅示例：

```json
{ "jsonrpc": "2.0", "id": 1, "method": "events.subscribe", "params": { "topics": ["agent.*"] } }
{ "jsonrpc": "2.0", "id": 2, "method": "agent.run", "params": { "input": "Hello" } }
{ "jsonrpc": "2.0", "method": "event", "params": { "topic": "agent.response.chunk", "data": { "content": "Hi!" } } }
```

详见 [events.*](./events)。
