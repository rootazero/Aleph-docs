`daemon.*` 暴露 Aleph 守护进程（`aleph-server` 进程内嵌网关）的控制面。所有处理器位于 `src/gateway/handlers/daemon_control.rs`；`daemon.logs` 在 `HandlerRegistry::new()` 阶段直接注册（不需要运行时状态），`daemon.status` / `daemon.shutdown` 在网关启动时由 boot 路径覆盖。

## 方法

| 方法 | 说明 |
|--------|-------------|
| [`daemon.status`](#daemonstatus) | 守护进程运行状态 |
| [`daemon.shutdown`](#daemonshutdown) | 优雅关闭网关 |
| [`daemon.logs`](#daemonlogs) | 按级别 / 行数读取最近日志 |

> `daemon.start` / `daemon.stop` / `daemon.restart` / `daemon.reload` 不是 RPC；守护进程的生命周期由宿主管辖（`aleph-server daemon`、`aleph-server service` 等 CLI 子命令，或 `systemd` / `launchd` 等服务管理器）。

### daemon.status

读取守护进程运行信息（uptime、版本、平台）。

**请求：**
```json
{ "jsonrpc": "2.0", "id": 1, "method": "daemon.status" }
```

**响应：**
```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": {
    "running": true,
    "uptime_secs": 1800,
    "version": "<build-version>",
    "platform": "linux-x86_64"
  }
}
```

`uptime_secs` 来自进程启动时刻的 `Instant`；`version` 来自构建时环境变量 `ALEPH_VERSION`。

### daemon.shutdown

触发优雅关闭：先发送响应，100 ms 后由 spawned 任务调用 `std::process::exit(0)`，进程退出码由 `aleph-server` 的 SIGTERM 处理器接管。

**请求：**
```json
{ "jsonrpc": "2.0", "id": 2, "method": "daemon.shutdown" }
```

**响应：**
```json
{ "jsonrpc": "2.0", "id": 2, "result": { "status": "shutting_down" } }
```

### daemon.logs

读取最近日志（按文件名匹配 `aleph-*.log.*`，取 mtime 最新者）。可选按级别过滤（按行内是否包含 ` ERROR ` / `[ERROR]` 等 token 的整词匹配，避免 `WARN` 误命中 `ERROR`）。

**请求：**
```json
{
  "jsonrpc": "2.0",
  "id": 3,
  "method": "daemon.logs",
  "params": { "lines": 50, "level": "error" }
}
```

**响应：**
```json
{
  "jsonrpc": "2.0",
  "id": 3,
  "result": {
    "logs": ["2026-03-15T10:30:00Z ERROR gateway: connection refused", "..."],
    "file": "/home/user/.aleph/logs/aleph-server.log.2026-03-15"
  }
}
```

当目录下没有任何 `aleph-*.log.*` 文件时返回 `{ "logs": [], "file": null, "total_lines": 0 }`。

**参数：**

| 参数 | 类型 | 必填 | 说明 |
|-----------|------|----------|-------------|
| `lines` | number | 否 | 返回尾部行数，默认 50 |
| `level` | string | 否 | 按级别过滤：`error` / `warn` / `info` / `debug` / `trace` |

## CLI 等效命令

| 用途 | CLI |
|--------|---------|
| 启动守护进程 | `aleph-server start` |
| 停止守护进程 | `aleph-server stop` |
| 注册系统服务（launchd / systemd-user / Task Scheduler） | `aleph-server service install` |
| 查看版本 / 平台 | `aleph-server version` |
