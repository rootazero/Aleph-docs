`a2a` 模块是 [Agent-to-Agent (A2A)](https://github.com/anthropics/a2a) 协议适配器。它让 Aleph 既能与外部 A2A 代理通信，也能在内部把子代理委派给外部实现。

> 文档历史版本的"domain/port/service/adapter"五桶划分仍然适用，但 `service` 子模块不再只有 `sub_agent`：现在 `service/` 同时承载 `card_builder` / `card_refresh` / `card_registry` / `notification` / `smart_router`。

## 概览

A2A 支持：
- **Agent Card 发现** —— 通过 `card_registry` 拉取并缓存 `AgentCard`；`card_refresh` 周期 + 健康监测
- **显式路由** —— `SmartRouter` 从已注册的 A2A 代理中匹配引号内的名称或别名。
- **子代理委派** —— `A2ASubAgent`（`a2a/sub_agent.rs`）把委派链内的 A2A 子代理接回 Aleph 的记忆 / 运行时
- **A2A 协议消息** —— `domain/message.rs::A2AMessage`（`text | file | data` Parts）、`A2ATask`（多轮 task with state machine）、`TaskState` 转换
- **客户端 / 服务端** —— `adapter/client/` 与 `adapter/server/` 是 A2A JSON-RPC 双向适配

## 域类型（`src/a2a/domain/`）

```rust
// agent_card.rs
pub struct AgentCard { /* name / description / url / version / capabilities / skills / provider / interfaces / security / extensions */ }
pub struct AgentProvider { pub organization: String, pub url: String }
pub struct AgentInterface { /* TransportProtocol + URL */ }
pub enum TransportProtocol { Grpc, HttpJson, WebSocket, /* … */ }
pub struct AgentSkill { /* id / name / description / tags / examples / input_modes / output_modes */ }
pub struct AgentExtension { /* uri / required / params */ }

// message.rs
pub enum A2ARole { User, Agent, System }
pub struct A2AMessage { pub role: A2ARole, pub parts: Vec<Part>, pub metadata: Option<JsonValue> }
pub enum Part { Text { text: String, metadata: Option<JsonValue> }, File(FileContent), Data(JsonValue) }
pub struct FileContent { pub name: Option<String>, pub mime_type: Option<String>, pub uri: String, pub bytes: Option<Vec<u8>> }
pub struct Artifact { pub name: Option<String>, pub parts: Vec<Part> }

// task.rs
pub enum TaskState { Submitted, Working, InputRequired, Completed, Canceled, Failed, Unknown }
impl TaskState { pub fn can_transition_to(&self, target: &Self) -> bool }
pub struct TaskStatus { pub state: TaskState, pub message: Option<A2AMessage> }
pub struct A2ATask { /* id / context_id / status / artifacts / history / metadata */ }
pub fn new(id: impl Into<String>, context_id: impl Into<String>) -> Self;
pub struct ListTasksParams { /* session_id / context_id / status / page_size / page_token */ }
pub struct ListTasksResult { /* tasks / next_page_token */ }
```

## Port 接口（`src/a2a/port/`）

```rust
// trait 形态：每个文件一个 trait，由 adapter 模块实现

// agent_resolver.rs   —— 把 AgentCard / agent_id 解析为可调用的 endpoint
// authenticator.rs    —— A2A auth scheme
// message_handler.rs  —— 入站 A2AMessage 处理
// streaming.rs        —— 流式响应（subscribe）
// task_manager.rs     —— 任务持久化 / 状态推进
```

每个 trait 由 `adapter::client`（远程 A2A 代理）与 `adapter::server`（本地 Aleph 暴露为 A2A）两侧实现。

## 服务层（`src/a2a/service/`）

```rust
pub use card_builder::CardBuilder;
pub use card_refresh::{refresh_all_cards, spawn_card_refresh, spawn_health_monitor};
pub use card_registry::CardRegistry;
pub use notification::{NotificationService, PushNotificationConfig};
pub use smart_router::{RoutingDecision, RoutingMethod, SmartRouter};
```

`SmartRouter::route` 通过 `AgentResolver` 读取已注册的代理，排除不可达条目，仅在匹配引号内的名称或别名时返回 `RoutingDecision`。`A2ASubAgent::execute_delegation` 按显式提供的代理 ID 或名称选择目标；未提供时调用路由器，再将任务发给解析到的端点。提交 `54e757c88` 移除了基于 LLM 的匹配；当前没有语义回退。

`spawn_card_refresh` + `spawn_health_monitor` 在后台保持 `CardRegistry` 新鲜；`refresh_all_cards` 一次性全量重拉。

## 子代理委派（`src/a2a/sub_agent.rs`）

```rust
pub struct A2ASubAgent { /* smart_router + client_pool */ }
pub struct DelegationOutcome { /* success / tokens / artifacts */ }

impl A2ASubAgent {
    pub fn new(smart_router: Arc<SmartRouter>, client_pool: Arc<A2AClientPool>) -> Self;
    pub fn with_raw_memory_writer(self, writer: Arc<dyn RawMemoryStore>) -> Self;
    pub fn with_capture_registry(self, registry: Arc<MemoryExtensionRegistry>) -> Self;
}
```

`A2ASubAgent` 把 A2A 子代理接回 Aleph：
- `with_raw_memory_writer` —— 让委派结果写入 Aleph 的 raw memory（`src/memory/store/`）
- `with_capture_registry` —— 注册记忆扩展捕获，让跨代理的成果被 memory system 看见
- 委派链内**闭包**——A2A 子代理可重新授权（`with_raw_memory_writer` 等就是重新挂接通道）

## Adapter 层（`src/a2a/adapter/`）

```
adapter/
├── auth/      # A2A auth 适配（Bearer / API key / OAuth）
├── client/    # A2A client 实现：JSON-RPC over HTTP / stdio
└── server/    # A2A server 实现：把 Aleph 暴露为外部可发现的 A2A 代理
```

客户端侧把 A2A JSON-RPC 调用映射到 Aleph `A2AMessage` / `A2ATask` 域类型；服务端侧则把 Aleph 的 agent registry 投影为 `AgentCard` + handler。

## 配置

```toml
[a2a]
enabled = true
max_sub_agents = 10
sub_agent_timeout = 300  # 秒
```

## 子代理树 RPC

`subagent.tree` 返回代理的子代理树（节点身份 + 实时事件 + 树 RPC）。`Interrupt` **真实取消 fan-out**（不再退化为入队）；长跑 detach 成员不再泄漏。
