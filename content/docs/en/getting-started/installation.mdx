This guide covers installing Aleph on your system.

## Prerequisites

- **Rust 1.95+** — needed to build from source (see `rust-version` in `Cargo.toml`)
- **just** — command runner (`cargo install just`)
- **npm** — needed to build the WASM panel UI
- **wasm-bindgen** — WASM JS bindings (`cargo install wasm-bindgen-cli`)
- **macOS 14+**, **Linux**, or **Windows** — primary supported platforms
- **SQLite** — bundled via `rusqlite` (no separate install needed)

### Platform-Specific Requirements

**macOS:**
- Xcode command-line tools
- Swift toolchain (for the desktop bridge)

**Linux:**
- `build-essential` or equivalent
- `pkg-config`
- `libssl-dev` (TLS uses `ring`; R3 keeps heavyweight deps out of core)

**Windows:**
- Visual Studio build tools
- `windows-sys` features handled automatically by Cargo

## Installation Methods

### Desktop App (Recommended)

The easiest way to run Aleph is the native desktop app. It bundles both the core server and the Tauri shell — no terminal required.

| Platform | Download | Notes |
|------|------|------|
| **macOS** | `.dmg` from [Releases](https://github.com/rootazero/Aleph/releases) | Universal binary (Intel + Apple Silicon) |
| **Linux** | `.deb` / `.AppImage` from [Releases](https://github.com/rootazero/Aleph/releases) | Debian, Ubuntu, Fedora |
| **Windows** | `.msi` from [Releases](https://github.com/rootazero/Aleph/releases) | Windows 10/11 |

The desktop app:
- Embeds `aleph-server` as a background daemon
- Hosts the Leptos Panel in a native webview
- Provides system tray, OS notifications, global hotkey (`CmdOrCtrl+Shift+A`)
- Silent auto-update through GitHub Releases
- Supports launch-at-login (Settings → General / tray menu; Windows via Task Scheduler)
- Auto-generates a self-signed cert when `[gateway.tls] cert/key` are left empty; SAN auto-discovers the host's non-loopback interface IPs; the Panel approves via TOFU and pins the fingerprint

### Using Just (Development)

For development or headless server deployment:

```bash
# Verify all build dependencies are installed
just deps

# Run the server in dev mode (rebuilds WASM)
just dev

# Build a release binary
just build

# Run tests
just test
```

### From Source

```bash
# Clone the repo
git clone https://github.com/rootazero/Aleph.git
cd Aleph

# Verify dependencies
just deps

# Run in dev mode
just dev

# Or build a release binary
just build
```

The release binary will be at `target/release/aleph-server`.

### Desktop Shell (Development)

```bash
# Run the desktop shell in dev mode (rebuilds daemon + shell)
just shell-dev

# Build platform installers (.app/.dmg, .msi, .deb)
just shell-build
```

### Verifying the Build

```bash
# Quick compile check
just check

# Run core tests
just test

# Check all crates, including desktop
just check-desktop

# Prompt scaffolding size (gated by R9's two rulers)
aleph-server prompt-size
```

## Directory Layout

Aleph creates the following under `~/.aleph/`:

| Path | Purpose |
|------|---------|
| `~/.aleph/` | Main config directory |
| `~/.aleph/aleph.toml` | Main config file |
| `~/.aleph/logs/` | Server logs (day-boundary auto-rotation + `ALEPH-BOOT` marker) |
| `~/.aleph/skills/` | User-installed Markdown skills |
| `~/.aleph/plugins/` | Extension plugins |
| `~/.aleph/mcp/` | MCP server configs and credentials |
| `~/.aleph/memory/` | Memory store (SQLite + sqlite-vec + notes) |
| `~/.aleph/cron/` | Cron job persistence (now real, not stubs) |
| `~/.aleph/artifacts/` | Artifact store (deliverables) |
| `~/.aleph/ops.log` | Signed operation ledger |
