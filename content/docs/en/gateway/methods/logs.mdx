title: "logs.*"
description: "System logs and diagnostics RPC methods"
---

`logs.*` exposes three methods for log-level control and log-directory lookup. All methods work on `RUST_LOG`-style filter strings (`error` / `warn` / `info` / `debug` / `trace`); the underlying primitives live in `src/logging/`.

## Methods

| Method | Description |
|--------|-------------|
| [`logs.getLevel`](#logsgetlevel) | Read the current global log level |
| [`logs.setLevel`](#logssetlevel) | Set the global log level |
| [`logs.getDirectory`](#logsgetdirectory) | Return the absolute path of the log directory |

> This namespace exposes the three endpoints above; use `daemon.logs` to read recent logs. See `src/gateway/handlers/logs.rs` and `src/gateway/handlers/daemon_control.rs`.

### logs.getLevel

Read the current process-wide log level (via `crate::logging::get_log_level()`).

**Request:**
```json
{ "jsonrpc": "2.0", "id": 1, "method": "logs.getLevel" }
```

**Response:**
```json
{ "jsonrpc": "2.0", "id": 1, "result": { "level": "info" } }
```

The `level` field is `LogLevel::to_filter_string()` output and accepts `error` / `warn` / `info` / `debug` / `trace`.

### logs.setLevel

Set the global log level. Takes effect immediately.

**Request:**
```json
{ "jsonrpc": "2.0", "id": 2, "method": "logs.setLevel", "params": { "level": "debug" } }
```

**Response:**
```json
{ "jsonrpc": "2.0", "id": 2, "result": { "ok": true, "level": "debug" } }
```

**Parameters:**

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `level` | string | Yes | `error` / `warn` / `info` / `debug` / `trace` |

An invalid value returns `-32602 Invalid params` with the valid set listed in the message.

### logs.getDirectory

Return the absolute path of the log directory. The directory is resolved by `crate::logging::get_log_directory()`; files are named `aleph-<service>.log.<date>` and rotate on day boundaries (an `ALEPH-BOOT` marker is written on startup).

**Request:**
```json
{ "jsonrpc": "2.0", "id": 3, "method": "logs.getDirectory" }
```

**Response:**
```json
{ "jsonrpc": "2.0", "id": 3, "result": { "directory": "/home/user/.aleph/logs" } }
```

For filtered reads of the files inside the directory, use [`daemon.logs`](./daemon#daemonlogs).
