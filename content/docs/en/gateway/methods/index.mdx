Use this index to find Gateway method names, role classifications, and existing reference pages.

## What the census records

`RPC_METHOD_CENSUS` in `src/gateway/method_census.rs` is a static test audit table, not a runtime discovery API. It records registered methods and `Class::Open` / `Class::Admin`, with tests comparing registrations and runtime rulings. Every name and classification below comes directly from that table; purpose labels explain names, not parameter or behavior contracts. Runtime classification is authoritative in `src/gateway/method_admin.rs`.

## Namespaces

Groups use the first prefix actually present in code. `agent` / `agents`, `session` / `sessions`, and `channel` / `channels` remain distinct; methods without a dot have their own groups. Source: `src/gateway/method_census.rs`.

## Open versus Admin

`Open` means the role gate does not require operator privileges; it does not bypass authentication, session ownership, resource policy, or transport restrictions. `Admin` requires operator privileges. An authenticated member calling an Admin method receives `AUTH_REQUIRED` (-32000) with the message below. See `src/gateway/method_admin.rs`, `src/gateway/server/connection/dispatch.rs`, and `shared/protocol/src/jsonrpc.rs`.

```text
Not authorized: this method requires operator privileges
```

To check a method locally, search the census and classification function in the code repository:

```bash
rg -n '"chat.send"' src/gateway/method_census.rs
rg -n 'method_requires_admin|MEMBER_CARVE_OUTS|ADMIN_PREFIXES' src/gateway/method_admin.rs
```
