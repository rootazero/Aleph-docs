# Changelog

Aleph follows CalVer (e.g. `26.7.21`). Releases ship multiple times per month; the version is kept in lock-step with the `VERSION` file and the `alephcore` crate. Breaking changes are flagged prominently in the release notes, but the API and architecture may evolve until 1.0. This page covers through 2026-11-26.

`VERSION` is still `26.9.1` after 2026-09-25 — the entries from 2026-09-26 to 2026-11-26 below record changes that are **merged on `main` but not yet released**.

<Callout type="info">
  This page is a **documentation-focused** summary derived from Aleph's main repository `CHANGELOG.md` and git history — it surfaces **user-visible** changes (features, CLI/RPC, config, security) and omits pure-internal refactor details. For the full record, see the [Aleph `CHANGELOG.md`](https://github.com/rootazero/Aleph/blob/main/CHANGELOG.md).
</Callout>

## 2026-11-26 — Memory self-evolution closure

The memory side turned "reflect → correct → distil" into a verifiable loop: missing dependencies surface before an attempt, feedback batches are validated before the cursor advances, and a successor note is published and verified before the old one is retired.

### Added

- **Dependency readiness first** (`7bd692733`) — a dream run reports missing dependencies to the model before it attempts anything; it fails closed and no longer overwrites the previous run's result.
- **Feedback batch recovery and validation** (`41b38ac2b`) — persisted feedback batches are recovered and validated before the cursor advances.
- **Successor published before retirement** (`66c82a1bd`) — the shared writer validates the successor's Markdown / SQLite / FTS state before retiring the original note.
- **Calibration and gate records** (`25ab346ce`, `9bac9d613`) — the calibration report for the self-evolution contracts plus the final gate outcome.

### Changed

- **Upstream merged** (`7fb540b44`) and **reflector branch merged** (`fbf1cfe53`) — both landed on `main`.

## 2026-11-25 — Capability model convergence, protocol surface growth, and the terminal rework

The capability layer drops the lifecycle state machine, the audit collector, the grant registry and the legacy handler table, and lets the resolution result plus the projection host carry the weight. In the same round the chat transcript, bounded history, the plugin reload preflight and owned worktrees land.

### Added

- **Plugin reload preflight** (`084453b9d`) — the new version is compiled before it replaces the running one; a compile failure refuses the reload instead of tearing the running version down.
- **Authorized chat transcript details** (`ed7dba611`) — `chat.transcript_details` returns tool cards, citations and context metering read-only.
- **Bounded history reads** (`b84632f85`, `9b83ab81e`) — bounded history comes back from the canonical PTY grid and in projection order.
- **One folded transcript** (`6e0cba213`) — ordered chat events fold into a single session transcript.
- **Unavailable dependencies are visible** (`ae9438dd5`) — an unavailable required dependency is reported to the model in a readable form instead of failing silently.
- **Authorized chat tool presentations** (`5d10304ab`) — chat tool presentations are streamed once the grant is in place.
- **PTY scrollback paging through the capability boundary** (`f660ebb83`) — terminal history is read page by page through the capability boundary instead of straight from the backend.
- **Older history prepended to the shared transcript** (`bf2e0b03e`, `82ddc741d`) — the panel prepends older history to the front of the shared transcript.
- **Rich Markdown and measured context** (`649f0504b`) — the panel renders rich Markdown assistant replies and shows the measured context usage.

### Changed

- **Owned worktrees** (`6b82702f6`) — sub-agents are forced into their own worktree through the mounted OS drivers.
- **Raw corrections are sequenced** (`8c65a29d8`) — corrections are ordered by their owning index and carry a status cursor.
- **Reflection attribution** (`86bcf95f3`) — reflection exposure is attributed to the source notes.
- **Bounded fold recovery** (`13e03d7b2`) — fold recovery is bounded and persisted summaries are accounted for.

### Fixed

- **Terminal refusals no longer leak session existence** (`893a91085`).
- **Transcript grants are fenced** (`9dd1b7d04`) — a missing diff is distinguished from no diff.
- **Shape validated only after admission** (`f49405f70`).
- **Top scroll anchor preserved** (`606122b67`) — and unavailable history is distinguished from empty history.
- **Selected conversation preserved** (`630bd63ee`) — across matching mounts.
- **Live chat reconciliation** (`18dd2d602`) — unconfirmed turns are no longer lost while reconciling.
- **Capability resolution details stay internal** (`f9008ed5f`).
- **obscura pinned and its gaps closed** (`c6f2d703d`) — the browser pins the obscura version and closes the gaps it opens.
- **Page-started navigation routed by frame id** (`0cb486484`).

### Removed

- **Capability lifecycle / activation state machine** (`459c4fe96`).
- **Unmounted audit collector and grant registry** (`8507aff30`).
- **Legacy handler registry and unmounted ambient module** (`4cb16e5b6`).

## 2026-11-24 — Desktop host and protocol v1 converge: dual Panel renderers, a shared TSX shell, one v1 method set

The desktop shape and the wire protocol changed in the same round: the Panel split into two renderers over one shared UI logic layer, the Gateway converged on a single v1 method set, and desktop IPC first landed as a read-only Unix channel plus a tier-gated Windows named pipe.

### Added

- **Dual Panel renderers over a shared UI logic layer** (`shared/ui_logic/src/panel/`) — one panel implementation now produces three artifacts: the Leptos WASM bundle (`interfaces/webchat/dist/`, embedded via `rust_embed` in `src/gateway/control_plane/assets.rs`), the TSX web package (interfaces/panel/out-web/, mounted at `/v1/panel/` via `[gateway].panel_web_dir`), and the TSX bundle (interfaces/panel/out-bundle/, embedded into the host via `include_str!` in `desktop/nsh-shell/build.rs`).
- **A shared TSX shell** (`interfaces/panel/`) — layout, SDK generations, and the web host; panel layouts become persistable under stable IDs.
- **The v1 method set** (`src/gateway/`) — three methods: `health` / `sessions.list` / `panel.capabilities.snapshot`, plus `panel_routes` and a CSP; the Gateway mounts the native TSX web v1 ingress on its TLS router.
- **A per-user subject in `system.hello`** (`src/gateway/`) — the handshake response carries a per-user derived `subject`: HMAC-SHA256, domain separator `aleph.panel.subject.v1\0`, first 16 bytes as hex. It is **not** an identity credential; it only correlates several connections belonging to the same user.
- **Desktop IPC** (`desktop/nsh-shell/`, `src/`) — opt-in read-only Unix IPC and tier-gated Windows named-pipe IPC; the client now uses bounded frames.
- **Shared memory graph read contracts and a read-only Nebula surface** (`5e1707f89`, `cd3ef045d`) — the memory graph is read-only under one contract and a node's identity is its note path; the Nebula lands as a read-only v1 surface.
- **Read-only Nebula rendering in the NSH Panel** (`e8cc2e7b1`) — the Nebula renders inside the shared NSH Panel instead of a second business UI.
- **Panel preferences, theme tokens and command rules** (`e795fca40`) — panel preferences and theme tokens move into the shared UI logic layer.
- **A command palette with rebindable shortcuts** (`c3712ff8d`) — a searchable command palette inside the Panel, with shortcuts that can be rebound.
- **A fixed two-column shell with appearance settings** (`10ff3bc39`) — the panel shell is fixed to two columns and wired to the appearance settings.

### Changed

- **Cold channel declaration** (`src/gateway/`) — declarative channel configuration no longer activates at startup; a declared or disabled channel is brought up only by an explicit start (`9976b7840`).
- **Severed config, link, and adapter wires removed** (`3df8e0401`) — the disconnected configuration found by the audit is deleted instead of lingering in the config surface.
- **The panel's text size applies on Desktop and Web** (`779cd18c5`).
- **`live_events` push and `chat.*` on the v1 endpoints** (`e0972bd96`).
- **A TSX Chat module with live streaming** (`1280a3647`).

## 2026-09-25 — Workflow Benchmark round-4 (Budget · Determinism · Fan-in/out · Structured Output)

Evolves workflow orchestration from "declarative + shared dispatcher" into a composite that is budgetable, statically guardable, fan-in/out-capable, and schema-enforceable — without introducing a vm/JS runtime or touching the harness.

### Added

- **WorkflowRunBudget runtime budget** (`src/workflow/budget.rs`) — `WorkflowRunBudget { total: Option<u64>, spent: AtomicU64 }` with `remaining()` / `try_charged(cost)` / `snapshot()`; uncapped uses the `total=None` path (not a `u64::MAX` fake cap); over-spend is refused without touching `spent`. The `materialize` entry reads `WorkflowDef::budget`. This round only wires *where* it is attached, not *how* cost is derived — `cost` is fixed at 1.
- **Determinism audit** (`src/workflow/determinism.rs`) — `audit_step_prompt(prompt) -> Vec<DeterminismFinding>` is a hand-written char-by-char scan that flags the `{now}` / `{time}` / `{timestamp}` / `{uuid}` / `{guid}` / `{random}` / `{random:N}` / `{rand}` runtime-variable references; double-brace `{{name}}` is out of scope (deterministic literal substitution). Runs as an advisory warn on save/import.
- **Parallel Step Group** (`src/workflow/def.rs` + `src/workflow/compile.rs`) — `WorkflowStepDef.parallel_group: Option<String>`; sibling steps in the same group share `[workflow_parallel_group, workflow_parallel_index, workflow_parallel_size]` metadata at materialize, with the index taken in declaration order. The dispatcher gains no new parallelism — Aleph already runs independent steps in parallel.
- **Collect Step** (`src/workflow/collect.rs`) — `WorkflowStepKind::Collect` variant + `collect_from: Vec<String>` + `reduce: Option<CollectReduce>`; `CollectReduce::{Concat | JsonArray | First}`, defaulting to Concat when unset. A collect step does not spawn an agent run; fan-in is achieved by the dispatcher.
- **`fail_unanswered_clarify` janitor** (`src/teams/dispatcher/schedule/reclaim.rs`) — `TeamDispatcher::fail_unanswered_clarify` (24h grace, disabled by default); pure predicate `should_fail_unanswered_clarify` guards the boundary.
- **SchemaOutput enforcer** (`src/teams/dispatcher/output_contract.rs`) — `SchemaOutcome::{Ok | ParseError | ValidationError}` + `validate_step_output(task, final_text)`; strips a ` ```json ``` ` fence, then validates with `jsonschema`; `schedule/mod.rs::finalize_step` is the sole entry point.

### Fixed

- **cancel/notified re-notification regression** (`src/teams/dispatcher/schedule/settle.rs`) — `is_cancel_provenance(task)` and `should_rearm_on_reopen(...)` as two pure functions; when `is_cancel_provenance=true` it never re-arms; cancel/rerun_failed/reopen are guarded by regression tests.

## 26.9.1 — Embedded Terminal + Project Rooms Bind to Channels + Subsystem Audit Sweep

Five days, 549 commits, two features and one very large sweep: the terminal becomes a first-class surface, project rooms bind to channel conversations, and a 40-defect audit sweep runs across every subsystem.

### Added

- **Embedded terminal, end to end** (`src/gateway/pty/`, `src/gateway/handlers/pty.rs`) — a character grid with wide-glyph and wrap semantics, scrollback, alternate screen, resize, cursor positioning, erase, C0 and SGR; the screen is held server-side and published as diffs on a 16 ms cadence; `pty.attach` replays into a gap-detecting client. The Panel gains a Terminal nav mode plus a canvas2d grid renderer.
- **Scoped terminal authority** — `pty.screen` / `pty.exit` delivery is bound to session ownership; spawn cwd is jailed to registered workspaces; daemon-aborting geometry is refused; a `[policies.terminal]` session gate ships live and default-on.
- **Project rooms bind to channel conversations** (`src/gateway/handlers/projects_channel.rs`, `qa/rooms_channel_bind`) — `projects.channel.bind` / `unbind` / `list`; a roster-gated binding arm; `session_store::rescope` takes a project id. Reachable from `aleph projects` on the CLI, from Panel room settings, and from `project_manage bind_workspace`.
- **`grep` and `find` become tools** — content search and filename discovery each get their own verb over the shared `.gitignore`-aware walk.
- **One search implementation** (`src/tools/scoped/search_steer.rs`) — each provider declares what it can express and the claim is pinned to the wire; an explicit provider is honoured; one call can fan out to several backends; the search tool stops discarding four fields.
- **A history window that loads earlier across clients** — protocol, CLI, TUI, and Panel share one vocabulary.
- **On-disk session damage repair** — normalizes millisecond `last_active_at` stamps, rebuilds torn `metadata.json` from the transcript, and quarantines what it cannot rebuild.
- **Windows shell unification** (`src/utils/shell.rs`, `qa/winshell/run.sh`) — pwsh → powershell → cmd ladder, UTF-8 + POSIX exit codes, two argv-ceiling thresholds.

### Fixed

- **SSRF and DNS rebinding closed as a class, not a list** — URL fetches carry policy, protocol-relative and percent-encoded bypasses are closed, the Discord token regex is anchored, and the PII email regex TLD quantifier is capped.
- **A failed run now reports that it failed** — the exit arm no longer fans all four `HarnessError` variants into `Cancelled`; one halt vocabulary spans protocol, CLI, TUI, and Panel.
- **The transcript has one order** — two backends each answered "what order?" separately, and two of the disagreeing paths were DELETEs.
- **`require_operator_tier` was fail-open on a missing `TurnContext`** — now closed.
- **Idempotency keys are namespaced by `(principal, method)`** — the connect rate limit no longer locks out an entire NAT.
- **`crate::sync_primitives` is now the only door** — canvas/identity/loop_graph/extension no longer reach past it into `std::sync`.
- **40 verified defects** across five subsystems + eight rounds of per-module logic audits + 22 numbered fix rounds; reports archived under `review-results/`.

## 26.7.18 — Self-Signed TLS + Client TOFU

A remote-access release that closes the loop on **self-signed TLS**. Two halves meet in the middle.

On the server: the self-signed certificate's SAN now **auto-discovers the host's non-loopback interface IPs** — a `wss://` connection to a LAN or public address no longer fails hostname verification — with a drift-tracking sidecar that reuses the cert when the interface set is a subset and regenerates it (never bricks) when it drifts or the sidecar is corrupt. On the client: the Panel gains **in-app trust-on-first-use (TOFU) certificate trust** — a self-signed gateway cert is reviewed and pinned from inside the app via a fingerprint + SAN approval splash with a TOFU/change warning, backed by a shared decision core and a pinned trust store. The macOS WKWebView cert-challenge adapter is the reference platform; iOS Keychain trust store and decision mirror wired alongside.

### Added

- **Self-signed cert SAN auto-discovery.** A new `[gateway.tls] san` field plus automatic discovery of the host's non-loopback interface IPs are assembled into the self-signed certificate's SAN.
- **SAN-drift sidecar.** An unchanged or subset SAN reuses the existing cert; a drifted one regenerates it; guarded by an atomic regen marker and a shrink-reuse test.
- **Panel in-app certificate trust (TOFU).** Shared decision core, pinned TOFU trust store, SHA-256 fingerprint + SAN/subject parsing, an approval splash page, and pending-cert state with approve/reject Tauri commands.
- **macOS WKWebView cert-challenge adapter + install dispatch.** The reference platform for in-app trust.
- **iOS Keychain trust store + decision mirror.** Unit-tested Keychain-backed trust for the iOS Panel.

### Fixed

- **Panel token wall buried by the boot gate** on a remote unauthorized connect — the token wall now surfaces.
